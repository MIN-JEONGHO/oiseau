# 공공데이터포털 파일데이터 등록 사전검토 프로그램  v2.0.0

> Powered by MIN · 배포 2026-07-28

『(파일데이터) 공공데이터 목록 및 데이터 등록 시 검토사항 및 반려 사유 안내(’26.2.~)』의
1~17번 항목을 코드로 옮긴 검토 도구입니다. 데이터 파일을 올리면 반려 사유가 될 항목을
**기준 조항 · 해당 셀 위치 · 조치 방법**으로 알려 줍니다.

## 실행

```bash
pip install -r requirements.txt

python main.py                                  # GUI 실행
python main.py data.csv                         # CLI 검토
python main.py 폴더경로 -x 검토결과.xlsx          # 폴더 일괄 검토 + 엑셀 리포트
python main.py data.csv -m meta.json            # 메타정보까지 함께 검토
python main.py data.csv --fix 서식               # 서식 정리만 적용 → data_수정.csv
python main.py data.csv --fix 내용               # 내용 변경 항목만 적용
python main.py data.csv --fix 반려               # 반려 등급 중 수정 가능한 조항
python main.py data.csv --fix all               # 자동 수정 가능한 모든 조항
python main.py data.csv --fix 10-타,10-하        # 조항 지정
python tests/test_rules.py                      # 회귀 테스트
```

CLI는 반려 항목이 하나라도 있으면 종료코드 1을 반환하므로 배치 스크립트에서 활용할 수 있습니다.

## 윈도우 exe 만들기

```bat
build_exe.bat
```

`dist\공공데이터_사전검토.exe` 단일 파일이 생성됩니다. GUI는 Edge WebView2 런타임을
사용하며 윈도우 10/11에는 대부분 기본 설치되어 있습니다. HTML·CSS·JS를 `checker/ui.py`
안에 문자열로 내장했으므로 `--add-data` 설정이 필요 없습니다.

## 픽스 — 선택한 조항만 자동 수정

검토 결과에서 고칠 항목을 직접 골라 수정본을 만듭니다. **원본 파일은 그대로 두고**
`파일명_수정.확장자`로 저장하며, **입력 형식(csv · tsv · xlsx · json)을 그대로 유지**합니다.
저장 후에는 수정본을 다시 검토해 결과 탭으로 추가하므로 반려 건수가 얼마나 줄었는지
바로 확인할 수 있습니다.

픽스는 세 단계로 나뉩니다. GUI의 픽스 옆 `?` 버튼에서도 같은 설명을 볼 수 있습니다.

**① 서식 정리** — 값의 뜻은 그대로 두고 표기만 기준에 맞춥니다. `서식 정리 N건 선택`으로
한 번에 고를 수 있습니다.

| 조항 | 자동 수정 내용 |
|---|---|
| 10-라 | 20231231 → 2023-12-31, 10;8;30 → 10:08:30 |
| 10-바 | 항목명 단위기호를 한글로(㎟ → (제곱밀리미터)), 나머지 특수문자 제거 |
| 10-차(하이픈) | 빈값 대체용 하이픈(-)을 공란으로 되돌림 (빈 셀에 값을 채우지는 않음) |
| 10-타 · 10-하 | 천 단위 콤마 제거, 지수표기 펼치기 |
| 10-더 | 셀 안 줄바꿈을 공백 한 칸으로 |
| 10-버 | 0212345678 → 02-1234-5678 (지역번호 없는 번호는 손대지 않음) |
| 10-파 · 10-러 | 콤마 구분자로 저장, UTF-8(BOM)으로 저장 |

**② 내용 변경** — 행이나 값을 지우거나 바꿔 원래 값이 사라집니다. 일괄 선택에 포함되지 않으며
하나씩 확인하고 체크해야 합니다.

| 조항 | 자동 수정 내용 |
|---|---|
| 10-나 · 10-다 | 주석 행, 소계·합계·평균 행 삭제 |
| 10-거 · 17-다 | 수식 오류값·깨진 문자 제거 |
| 10-서 | HTML 태그 제거 |
| 10-머 | 주민번호·휴대전화·이메일 마스킹 |

**③ 자동 수정 불가** — 담당자의 판단이 필요해 프로그램이 손대지 않습니다. 지적사항 카드에
잠금 표시와 사유가 함께 나옵니다.

| 조항 | 사유 |
|---|---|
| 10-자 | 빈 항목명은 실제 뜻에 맞게 담당자가 지어야 합니다. 임의로 채우지 않습니다. |
| 10-차(빈 셀) | 빈 셀을 임의의 값으로 채우지 않습니다. 공란 사유를 기타유의사항에 기재하세요. |
| 10-버(지역번호) | 지역번호는 담당자가 확인해 추가해야 합니다. |
| 10-파(열 수 불일치) | 값의 경계를 알 수 없어 직접 확인해야 합니다. |
| 10-아 | 데이터값을 임의로 만들어 넣을 수 없습니다. |
| 10-카 | 공란 사유는 기타유의사항에 직접 기재해야 합니다. |
| 10-너 | 깨져서 생긴 물음표의 원래 글자를 알 수 없습니다. |
| 10-사 | 적절한 한글 항목명은 담당자가 정해야 합니다. |
| 12-다 · 13-가 | 코드 대응값·데이터 보강은 자동화 대상이 아닙니다. |

CLI에서는 `--fix 서식`, `--fix 내용`, `--fix 반려`, `--fix all`, `--fix 10-타,10-하` 형태로
같은 구분을 사용합니다.

> 같은 조항 번호를 여러 지적사항이 나눠 쓰는 경우가 있어(예: 10-차 = 빈 셀 + 하이픈 대체,
> 10-버 = 하이픈 누락 + 지역번호 누락), 픽스 대상은 조항 번호가 아니라 지적사항별
> **픽스 키**로 판별합니다. 그래서 같은 10-차라도 하이픈 대체만 수정 대상이 되고
> 빈 셀은 수정 불가로 표시됩니다.

## 셀 위치 지도

검토 결과를 파일의 셀 격자에 그대로 얹어 보여줍니다. **최대 100열 × 10000행**까지 표시하며,
파일이 그보다 작으면 실제 크기(예: 30열 × 4000행)까지만 그립니다. 보이는 영역만 캔버스에
그리는 방식이라 행이 많아도 스크롤이 끊기지 않습니다.

- 지적사항의 셀 좌표 칩을 누르면 지도가 그 위치로 이동합니다.
- 지도의 색칠된 셀을 누르면 해당 지적사항 카드로 이동해 깜빡입니다.
- 셀 위에 마우스를 올리면 좌표와 등급이 우측 상단에 표시됩니다.

## 자동 검사 항목

| 조항 | 검사 내용 |
|---|---|
| 1 목록명 | 허용 외 특수문자, 주기·기준년월일 표기, 통계 발간물 예외, 기관명_데이터명 형태 |
| 2 데이터명 | 기준일자 포함, 기관명 중복 기재 |
| 3 키워드 | 개수(3~8), 띄어쓰기만 다른 중복, 데이터명·기관명 중복, 특수문자 |
| 4 데이터 설명 | 50자 미달, 연속 띄어쓰기, 동일 단어 반복, 연도 일치 확인 |
| 5 중복 등록 | 목록 제외 요청 서식 안내(수동 확인 항목) |
| 6 링크데이터 | 500MB 이상 링크 전환, 링크 상세페이지 요건 안내 |
| 7 공공누리 | 유형 미선택·오입력, 저작물 이용허락 동의서 필요 여부 |
| 8 비정형 데이터 | 이미지·동영상·음성별 비식별화 점검, ZIP 묶음, shp·sav 설명파일 |
| 9 파일 확장자 | 비개방형 포맷(HWP·XLS·DOC·PPT), ZIP 내부 확장자·이중압축, 오픈포맷 단계 |
| 10 CSV 기준 | 항목명·데이터 구조, 주석·집계 행, 날짜·시간 구분기호, 기간 범주화, 항목명 특수문자·영문 표기, 공란, 천단위 콤마, 구분자, 지수표기, 수식오류, 깨진 물음표, 셀 내 줄바꿈, UTF-8 안내, 개인정보, 전화번호, HTML 태그 |
| 11 데이터 기준일 | 파일 내 최근 날짜 추출 후 입력값과 대조 |
| 12 개방목록 일치 | 날짜만으로 구성, 코드 전용 열(코드북), IP·DB 등 부적절 항목, JSON 구조 |
| 13 최소 규모 | 3열·5행(값 15개) 미달 |
| 14 제공신청 | 제공번호 누락, PDF 개방 시 제공신청 |
| 15 데이터 언어 | 메타데이터에 한글·영문 외 문자 |
| 16 차기 등록 예정일 | 갱신주기 대비 예정일 미설정 |
| 17 기타 상세 | 등록 확장자 불일치, 단위 누락, 인코딩 깨짐 |

판정은 **반려 / 보완필요 / 확인권장 / 적합** 4단계입니다. 보완필요는 기타유의사항 기재 등
조건을 충족하면 승인 가능한 항목, 확인권장은 담당자가 직접 눈으로 확인해야 하는 항목입니다.

```
main.py                진입점 (인수 없으면 GUI)

  models.py            판정 등급·지적사항(픽스 키 포함)·결과 자료구조
  readers.py           인코딩·구분자 추정, CSV·XLSX·ZIP 판독
  rules_csv.py         10·12·13·17번 (표 형식 전수 검사)
  fixer.py             선택 조항 자동 수정 (형식 유지 저장)
  rules_file.py        6·8·9번 (확장자·비정형·용량)
  rules_meta.py        1~5·7·11·14~16번 (등록 메타정보)
  engine.py            형식별 판독 후 룰 실행
  report.py            콘솔·엑셀 리포트
  cli.py               명령줄 인터페이스
  gui.py / ui.py       데스크톱 GUI
samples/               정상·위반 예시 CSV
tests/test_rules.py    회귀 테스트
```

## 지원 형식

| 형식 | 검토 | 픽스 |
|---|---|---|
| CSV · TSV · TXT | 전수 검사 | 지원 (원본 인코딩 유지, 필요 시 UTF-8 BOM) |
| XLSX · XLSM | 첫 시트 검사 | 지원 |
| JSON | 객체 배열을 표로 펼쳐 검사 | 지원 (구조·키 순서 유지) |
| ZIP | 내부 CSV 최대 5개 검사, 확장자·이중압축 점검 | 미지원 |
| 그 외 | 확장자·용량·비정형 기준만 검사 | 미지원 |

## 한계

포털 등록 여부 조회(5번), 링크 접속 확인(6번), 공공누리 마크 육안 확인(7번),
이미지·영상 내 개인정보 판별(8번)은 자동화 대상이 아니며 체크리스트로만 안내합니다.
검토 기준이 개정되면 `checker/rules_*.py`의 해당 조항 함수만, 픽스 정책이 바뀌면
`checker/fixer.py`의 `FIXABLE` 표만 수정하면 됩니다.
