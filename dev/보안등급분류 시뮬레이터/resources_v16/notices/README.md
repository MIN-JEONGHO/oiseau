# 고정 고시 기준본

이 폴더는 네 범위의 공식 원문 전체와 보수적으로 정규화한 검토 조건을 함께 보관합니다. 실행 중 웹에서 갱신하지 않습니다.

기준본 이름(`catalogue_id`)은 `kr-notices-v16-1`입니다. 날짜처럼 보이는 이름을 쓰지 않습니다. v15 기준본(`kr-notices-2026-10-21-v3`)과 비교하면 `raw/`·`extracted/`·`normalized/`·`review/` 파일은 바이트까지 같고, `manifest.json`의 출처마다 고시일(`announcement_date`)이 `effective_date` 바로 앞에 더해졌으며, 이 README가 바뀌었습니다. 판정 방식 동일. 다만 기준본 지문과 AI에 함께 보내는 고시 정보(기준본 이름, 확인값, 출처별 날짜)가 달라지므로 판정 결과가 v15와 같다고 보장하지 않습니다.

고시일과 시행일을 구별합니다. 첨단 고시는 2025-05-12 고시, 2025-05-18 시행입니다. 핵심 고시는 2025-10-02 고시, 2025-10-02 시행입니다. 전략물자 고시는 2026-08-31 고시, 2026-09-01 시행입니다. 생성 도구는 같은 고시번호의 본문 HTML 머리글(예: `[시행 2026. 9. 1.] [산업통상부고시 제2026-101호, 2026. 8. 31., 일부개정]`)에서 고시일·시행일을 읽고 위 값과 대조합니다. 값이 다르거나 머리글을 찾지 못하면 생성을 실패로 끝냅니다. 별표 PDF·HWPX에는 고시일이 없으므로 같은 고시번호의 본문 값을 씁니다. 원문 수집 시각(`retrieved_at`)은 고시일이 아니며 v15 값 그대로입니다.

`reviewed/full`은 공식 원문 전체 범위·지정항목·통제번호·좌표·주석의 보존 구조를 검수했다는 뜻입니다. 모든 법률 조건을 완전하게 기계 해석했다는 뜻이 아닙니다. 507개 지정/통제 검토 단위 중 수치·정성 완전 AST 41개, 정성 완전 AST 49개, 일부 구조화했지만 미해석 분기가 남은 3개, 원문 전체를 미해석으로 보존한 414개입니다. 수치 leaf는 57개입니다. 검수 집계와 원문별 해시는 `manifest.json` 및 `review/review.json`에 있습니다. 미해석 `unsupported`는 반드시 정보 부족으로 처리합니다. AI에게 수치 판정을 대신 맡기지 않습니다.

실제 구조화 사례에는 첨단 배터리 형상별 에너지밀도와 21mm 경계, QD 색재현율·반치폭 및 LCD/모듈 제외, 핵심 연료전지의 전류밀도·운전시간·출력·발전효율·내구성, 이중용도 1A003의 두께/코팅 OR와 구리/PCB 예외, 3A102 열전지의 300km 초과 사거리 정의, 1A006 원격 IED 처리 및 동반 조작자 예외, 군용 ML22의 공개정보·기초과학연구 등 예외가 포함됩니다. 1A006의 전용 구성품·부속품은 장비 자체와 별도의 분기로 보존하며 상위 장비의 해당 범위는 추가 검토로 남깁니다. ML22의 양의 통제범위도 여전히 미해석이므로 예외가 없다는 이유만으로 통제 해당을 확정할 수 없습니다.

첨단 제4조의 ‘각 기술에 특화되어 양산을 목적으로 개발되거나 양산에 사용되는 기술’ 조건을 별도로 보존합니다. 정규화된 첨단 판정 AST에도 이 조건을 포함합니다. 별표 2 부록의 축약 반복 통제번호를 본표의 독립 통제항목과 합치지 않습니다. `field="공통정의·주석"`인 기록은 참조 자료이며 독립 지정항목이 아닙니다. `qualifier_refs`는 출처·정의·주석을 추적하는 참조이며 무조건 AND할 조건 목록이 아닙니다. 실제 판정 논리는 각 조항의 `condition`에 있습니다.

별표 2·3은 같은 확정 고시 본문에 연결된 공식 HWPX를 원본으로 사용합니다. 2026-10-21 획득 시각과 SHA256, 동일 고시의 PDF 링크·해시는 `review/structured-source-verification.json`에 기록합니다. PDF의 2026-10-20 획득 기록은 그대로 보존합니다. HWPX 표·셀의 완결 문단을 국문과 영문 각각 PDF 텍스트에 대조한 후 조항에 배정합니다. 다음 통제번호나 표제가 문단 중간 높이에 인쇄돼도 이전 문단 말미를 잘라 이동하지 않습니다. 국·영문 표제 전환 110건(각 언어 55건), 독립 PDF 단어 좌표의 이중용도 387개·군용 22개 본표 통제번호를 검증합니다. 본문 열에 인쇄된 0D001도 독립 통제번호입니다. 1C901.a/b는 하나의 본표 1C901에 속하며 민감 부록의 반복 코드는 별도 통제항목이 아닙니다.

`extracted/*.paragraphs.json`에는 모든 원본 표·셀 문단의 텍스트, 빈 문단 위치, 수식 스크립트와 중첩표, PDF 대조 위치를 보존합니다. `review/control-boundaries.json`은 별표 2의 유효 문단 17,058개와 별표 3의 2,283개 각각에 대해 유일 소속과 조항 본문 내 문자 범위·해시를 기록합니다. 중첩표 2개의 문단 702개(빈 셀 문단 포함)도 부모 문단 소속으로 모두 기록합니다. HWPX 전체 문단 수는 각각 38,528개와 3,502개이며 빈 문단·도형·머리꼬리 문단을 구분합니다. 원본 수식 28개와 PUA 기호를 임의의 수치나 다른 문자로 바꾸지 않습니다. 본문과 PDF 표시의 차이 47문단은 수식 렌더링 19건, 중첩표의 셀/시각행 순서 2건, PUA 기호 4건, 군용 반복 ML 도형이 본문 추출에 겹친 22건으로 전수 기록합니다. 원문·앵커·소속·원문 및 PDF 대조 해시와 변경 문자 목록을 함께 검증합니다. 문자 정규화는 위치 대조에만 사용하며 보존 원문이나 수치 판정에 적용하지 않습니다.

2E003.f의 ‘표와 기술해설은 2E503.g 이후에 나옴’이라는 원문 안내에 따라, 뒤에 배치된 코팅공정 표와 기술해설 전체를 2E003에 보존하고 검수 예외로 기록합니다. 이 구간의 물리적 위치를 이유로 2E503의 조건으로 붙이지 않습니다. 수식·표를 포함한 복잡한 조항은 여전히 `unsupported`이며, 표시 요소 보존이 의미 자동판정 지원의 확대를 뜻하지 않습니다.

SHA256은 `7ac7c95621584be46c02b422e8f8c1ec481bf76382754d9ce24fda13019538bb`입니다. 이 초안과 일부개정안 ZIP은 실행 자료에서 제외하고 법제처의 확정 통합본을 사용합니다.

## 재생성 및 갱신

`raw/` 원문과 `.gitattributes`는 `resources_v15/notices`에서 바이트 그대로 복사한 것입니다. 개발용 PyMuPDF 2.0 및 lxml 6.1.1 환경에서 프로젝트 루트 기준 다음 명령을 실행합니다. 원문을 로컬에서 읽고 네트워크나 모델 API를 호출하지 않습니다. 재생성한 `raw/`·`extracted/`·`normalized/`·`review/` 파일이 v15와 바이트까지 같지 않으면 그 결과를 받아들이지 않습니다.

```powershell
python tools/build_notice_catalogue_v16.py
python -m unittest discover -s tests -p test_v16_catalogue.py
```

새 고시로 갱신할 때는 공식 통합본문·전체 별표를 획득하고, 시행/발령 및 확정 여부를 확인한 후, 원문 차이와 지정항목·통제번호·정의·예외·단위를 검수해야 합니다. 새 버전은 별도 catalogue ID로 발행합니다. 기존 실행의 버전과 원문은 소급 교체하지 않습니다. 파서는 고정 원문의 분야별 건수와 통제번호 건수에 대한 방어 검사를 포함하므로 새 버전은 코드 및 회귀 검수를 거쳐야 합니다. 실행 loader는 표준 라이브러리만 사용하며 파일·조항 해시, 경로, 참조, 네 범위의 검수 완료를 모두 확인한 뒤 불변 객체를 반환합니다.

범위는 별표 2·3의 연구기술 관련 대조입니다. 상황허가, 국가별 제재, 실제 수출허가 최종 판단은 포함하지 않습니다. 여기의 결과는 전문 판정을 대신하지 않습니다. 원문은 국가법령정보센터가 공개한 행정규칙이며 출처와 원래 내용, 해시를 함께 보존합니다.
