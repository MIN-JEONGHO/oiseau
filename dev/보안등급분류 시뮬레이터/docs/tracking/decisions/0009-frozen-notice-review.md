# 고정 공식 고시와 현재·목표 사양 대조

## 배경

사용자는 체크리스트·국가영향 지표 모두에서 국가첨단전략기술·국가핵심기술·전략물자 고시의 세부 사양·수치·예외를 대조하고 근거와 부족정보를 화면·엑셀·HWPX에 남기도록 승인했다. 연구과제의 개발목표를 현재 확보 성능으로 읽으면 해당 가능성과 실제 보유 기술이 혼동된다.

## 결정

공식 기준본을 버전 고정하고 개정본은 검토 후 새 배포로 갱신한다. 전략물자는 이중용도 별표 2와 군용 별표 3을 함께 다루며 상황허가·국가별 제재·실제 수출허가 결정은 분리한다. 현재 사양과 개발목표 사양을 따로 대조하고 목표 조건 전체 충족 때만 ‘목표 달성 시 해당 가능성’으로 표시한다.

## 대안과 판단

실행마다 최신 고시를 자동 조회하면 개정 반영은 빠르지만 같은 과제의 과거 근거 재현과 개정본 검수가 어렵다. 키워드 후보만 출력하면 구현은 단순하지만 용도·수치·예외가 빠진 해당 오판 위험이 크다. 모든 원문을 모델이 자유 해석하게 하면 지원 폭은 넓지만 검수되지 않은 조건을 확정할 수 있다. 고정 원문·검수 조건·불완전 상태를 함께 보존하는 방식을 선택했다.

## 영향

schema2 결과에 기준본 manifest·지문·후보 및 전체 참조 스냅샷·인용 사실·조건별 판단·부족 질문을 저장한다. 수치와 조건식은 검증 가능한 계산으로 평가하며 미해석 조건과 근거 없는 정성 판단은 정보 부족으로 남긴다. 571개 기록의 전체 원문 확보는 507개 실항목 전체의 자동 의미 판정 지원을 뜻하지 않는다. 새 고시 검수 전 런타임 교체는 하지 않으며 과거 문서 재출력은 당시 저장 근거로만 수행한다. 해시는 자료 인증이나 공식 판정서를 대신하지 않는다.
