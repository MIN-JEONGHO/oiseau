# 운영 기준 v12와 v13 검토 구분

## 배경

IDE의 활성 파일은 `security_grade_classifier_v13_test.py`이지만 사용자는 실제로 활용하는 버전이 v12라고 확인했다. v12용 배포 설정도 v12 스크립트를 가리킨다. 가장 큰 버전 번호만 보고 작업하면 운영 대상과 검토 대상이 뒤바뀐다.

## 결정

실제 활용 기준은 `security_grade_classifier_v12.py`로 기록한다. v13은 마지막 의견 엄격도를 추가한 후속 검토 대상으로 구분하고, v12와 이전 파일을 보존한다. `_claude` 변형을 별도 확인 없이 운영 기준으로 바꾸지 않는다.

## 대안과 판단

v13을 즉시 운영 기준으로 간주하면 열린 파일과 개발 작업을 일치시킬 수 있지만 사용자의 실제 운영 사실과 v12 배포 구성이 어긋난다. 모든 버전을 한 파일로 합치면 중복을 줄일 수 있지만 과거 동작을 보존하는 방식과 충돌하며 이번 범위를 넘어선다.

## 영향

v13 수정은 v12 실행 파일에 반영되지 않는다. 운영 전환에는 별도의 대상 결정·검증·패키징 확인이 필요하다. 현재 결정으로 v13의 향후 도입을 금지하지 않으며, v12가 최신 확정 기준을 이미 충족한다는 의미도 아니다.
