# 두 판단 방식 중 하나 선택

사용자는 체크리스트와 국가영향 지표를 동시에 실행하는 복합 선택 대신 두 가지 중 하나를 선택하도록 승인했다. 두 방식을 한 결과에 섞으면 점수 유무와 개인별 판단의 의미가 모호해진다.

한 단건·대량 실행은 checklist 또는 impact만 사용하고 시작 때 옵션을 고정한다. 체크리스트는 해당 여부·법적 정의·보호 필요성을 검토하며 수치는 산출하지 않는다. 지표는 공통 항목·가중치로 독립 에이전트 점수를 계산하고 마지막 정의 판단과 종합 의견을 낸다.

복합 모드는 추가 평가 비용과 상충 결과 처리 규칙이 필요하므로 채택하지 않는다. 체크리스트에서는 가중치 입력을 비활성화하고 문서 수치를 해당 없음으로 표시한다. 두 방식 모두 조건부 8번·불완전 응답·실제 위원회와 AI 참고의 구분을 유지한다.
