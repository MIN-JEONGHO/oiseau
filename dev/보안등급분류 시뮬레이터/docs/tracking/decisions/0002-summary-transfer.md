# 과제요약의 외부 전송과 로컬 사용

## 배경

이 도구는 분류 판단에 과제정보가 필요하며 외부 모델과 로컬 모델을 모두 지원한다. 사용자는 분류 판단을 위해 과제요약정보를 전송하는 선택을 수용하고, 전송이 불가능하면 로컬 모델을 써야 한다고 밝혔다.

## 결정

외부 모델로 과제요약을 전달하는 사용과 로컬 모델 사용을 모두 유지한다. 외부 전송이 불가능한 경우에는 로컬 모델을 활용한다. 외부 전송 수용 범위는 과제요약정보이며 추가 문서·원문 전체의 반출 허용으로 확대하지 않는다.

## 대안과 판단

모든 과제를 로컬로만 처리하면 외부 전송을 피할 수 있지만 사용자가 수용한 외부 모델 활용 선택을 없앤다. 모든 과제를 외부로만 처리하면 외부 전송 불가 상황에 대응할 수 없다. 따라서 한 제공자 방식으로 고정하지 않는다.

## 영향

실제 전송 목적지와 입력 정보의 범위를 확인해야 한다. 로컬 제공자 이름만으로 서버가 내부에 있다고 보장할 수 없다. 이 결정만으로 제공자의 보관·학습 계약, 기관 반출 절차, 사용자별 접근 권한과 파일 보관기간이 확정되지는 않는다.
