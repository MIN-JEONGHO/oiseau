# 표준 의견 고정과 자동 가중치 1.0

## 배경

과거 v13·v14는 엄격·표준·관대의 마지막 의견 선택을 제공했다. 사용자는 v15에서 마지막 의견 엄격도를 UI에서 없애고 표준으로 두도록 지시했으며 공통 항목 자동선택 때 실제 가중치를 1.0으로 하고 안내하도록 요청했다. 이전 수동 설정이 자동 실행에 남으면 화면 선택과 실제 계산이 달라질 수 있다.

## 결정

v15는 마지막 의견을 표준으로 고정하고 엄격도 UI를 제거한다. 직접 API 옵션으로도 다른 값을 거부한다. 자동 항목 선택은 수동 selected_items·weights·weight_tolerance의 잔존값을 읽지 않고 정규화하며 실제 선택 항목의 가중치를 모두 1.0으로 한다. 직접 선택의 범위·선택 평균 검사는 유지하고 체크리스트에는 수치를 적용하지 않는다.

## 대안과 판단

UI만 숨기고 과거 설정을 수용하면 이전 저장값이나 직접 호출에 따라 보이지 않는 엄격도가 적용된다. 자동에서도 수동 가중치를 보존하면 사용자의 1.0 요구와 다르며 입력 형식 오류가 자동 실행을 막을 수 있다. 모든 가중치를 없애면 단순하지만 승인된 직접 선택 기능까지 제거한다. 따라서 표준 고정·자동 1.0과 직접 가중치를 구분한다.

## 영향

v15에서 엄격도 선택에 따른 비교 실행은 제공하지 않는다. v13·v14의 엄격도 선택은 보존된 과거 실행 경로에만 남는다. 마지막 의견과 수치 계산을 분리한다는 원칙은 유지하되 엄격도를 선택 가능하게 둔 과거 결정의 적용 범위를 v15에서는 표준 고정으로 바꾼다. 자동 잔존값은 실행 지문에도 영향을 주지 않으며 결과·화면·엑셀·HWPX는 실제 가중치 1.0을 일관되게 사용한다.
