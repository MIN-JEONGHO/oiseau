# 사례보다 본문 정의와 산식 우선

승인된 최종 가이드라인의 일부 예시에는 가중치 평균·표시 점수·개인/취합표 숫자·등급별 조항의 불일치가 있다. 예시를 그대로 계산 정답으로 복제하면 본문과 충돌한다.

v14는 본문 법령·정의·산식을 구현 기준으로 삼는다. 사례는 문서 구성·설명 수준에 활용한다. 에이전트 점수는 Σ(가중치×점수)/선택항목수, 에이전트 평균은 완전한 전체 예정 에이전트의 평균이며 중간 반올림하지 않는다. 가중치는 0.8~1.2이고 선택 항목 평균 1.0이다.

사례 숫자에 맞추는 대안은 재현 가능한 본문 계산을 깨뜨린다. 따라서 3.875 예와 3.5/4.5 경계·가중치 조건을 자동 검증한다. 구간은 우선 검토 기준이며 법적 정의 판단을 대체하지 않는다. 원본을 수정하거나 사례를 공식 정답으로 배포하지 않는다.
