# 앱이 호출하는 Windows 보안 저장소

사용자는 키 재입력의 번거로움을 줄이되 별도 Windows 설정창 조작이나 저장 비밀번호가 없는 흐름을 원했다. 평문 설정파일은 배포·로그·공유 과정에서 키가 노출될 수 있다.

앱은 현재 계정의 Windows 일반 자격증명을 제공자별로 자동 저장·로드·교체·삭제한다. 같은 PC·계정에서 재사용하며 앱 버전 숫자가 달라졌다고 저장 이름을 바꾸지 않는다. 새 입력→제공자별 저장 키→환경변수 순서로 사용하며 환경변수는 자동 영구 저장하지 않는다.

평문 우회 저장과 별도 암호 입력은 채택하지 않는다. 저장 실패 시 사용자에게 알리고 이번 실행의 메모리 입력을 허용한다. 키 삭제는 앱 항목·현재 입력·메모리 범위이며 제공자 계정 폐기는 아니다. 실제 저장소 시험은 무작위 전용 이름·가짜 값만 사용하고 시험 항목을 정리한다.
