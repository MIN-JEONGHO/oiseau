## 두 가지 방식과 공통 항목

한 실행은 체크리스트 또는 국가영향 지표 한 가지만 사용한다. 기본은 국가영향 지표다. 후보가 명확히 제외되면 후보제외와 이유를 남기며 최종 참고 등급은 비운다. 정보 부족을 후보 제외나 일반 확정으로 바꾸지 않는다.

체크리스트는 항목 해당 여부·법령상 정의·보호 필요성을 에이전트별로 평가한다. 점수·가중치·평균을 산출하지 않으며 완전한 검토의 미해당과 판단곤란·누락 응답을 구분한다.

국가영향 지표는 자동 또는 직접 선택한 공통 항목으로 에이전트별 평가를 한다. 자동은 해당·일부·판단곤란 항목을 관련 대상으로 선택하고 실제 선택 항목의 가중치를 모두 1.0으로 한다. 남아 있는 수동 선택·가중치·허용오차 값은 자동 실행에 영향을 주지 않으며 화면에도 자동선택 시 가중치 1.0을 안내한다. 적용 항목이 없으면 0점·일반과제로 만들지 않고 검토필요로 남긴다.

직접 선택은 각 가중치 0.8~1.2, 선택 항목 평균 1.0(허용오차 최대 0.000001)을 검사한다. 누락한 선택 항목 가중치는 1.0이며 조건 위반값을 자르거나 평균에 맞춰 임의 조정하지 않는다. 체크리스트에는 가중치를 적용하지 않는다.

유효 점수는 1~5 정수다. 에이전트 점수는 Σ(항목 가중치×해당 에이전트 점수)/선택 항목 수다. 전체 예정 에이전트 1개 또는 3개의 점수가 완전할 때만 종합 평균을 계산한다. 중간 반올림하지 않고 원값을 보존하며 표시만 반올림한다. 예: 1.2·1.1·0.9·0.8과 5·4·3·3은 3.875(표시 3.88)다. 표시값이 경계를 가리면 원값 또는 추가 자릿수를 보여준다.

원값 4.5 이상은 보안과제, 3.5 이상 4.5 미만은 민감과제, 3.5 미만은 일반과제의 우선 검토 구간이다. 법적 정의를 대체하는 자동 지정 임계값이 아니다. 구간과 다른 참고 의견에는 법적 근거·논의사항·낮은 신뢰도를 남긴다.
