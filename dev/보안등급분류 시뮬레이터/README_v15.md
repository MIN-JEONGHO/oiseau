# 연구보안 등급분류 시뮬레이터 v15

Windows 설치형 웹 UI에서 과제정보, 고시 근거, AI 에이전트의 참고 의견과 HWPX를 함께 확인합니다. 브라우저 창이나 웹사이트 배포 없이 앱 한 창으로 실행합니다. v12는 별도 운영 전환 결정 전까지 실제 운영 기준이며 v12~v14 파일은 보존합니다. 출력은 기관의 심의·의결·등급 확정을 위한 참고자료입니다.

## 실행 환경

확인 환경은 Windows AMD64, Python 3.14.6, pywebview 6.2.1, Microsoft Edge WebView2 Runtime입니다. 실행 파일에는 Python과 앱 의존성을 포함하지만 WebView2 Runtime과 .NET Framework 4.6.2 이상은 PC에 설치되어 있어야 합니다. WebView2Loader.dll을 포함해도 브라우저 런타임 설치를 대신하지 않습니다.

소스로 실행할 때 프로젝트 폴더에서 별도 환경을 만듭니다.

```powershell
python -m venv .venv_v15
.\.venv_v15\Scripts\python.exe -m pip install -r requirements_v15.txt
.\.venv_v15\Scripts\python.exe -X utf8 -B .\security_grade_classifier_v15.py
```

WebView2를 사용할 수 없으면 앱은 고정된 설치 안내를 표시하고 종료합니다. Microsoft의 [WebView2 Runtime 설치 안내](https://developer.microsoft.com/microsoft-edge/webview2/)에서 Evergreen Runtime을 설치하거나 복구한 뒤 다시 실행합니다. 구형 Internet Explorer 엔진으로 전환하지 않습니다. 의존성 누락 시 위 환경에서 requirements를 다시 설치합니다. 실제 설치·보안 정책은 기관 PC 담당자에게 확인합니다.

## 검토 순서

1. **모델·설정**에서 Claude Sonnet 5.5 (`claude-sonnet-5-5`), OpenAI GPT-6 Luna (`gpt-6-luna`), Ollama 또는 LM Studio를 선택합니다. 외부 모델 식별자는 고정이며 다른 모델로 자동 대체하지 않습니다. 계정의 모델 이용 권한과 인증 성공은 실제 사용 때 확인합니다. 로컬 모델은 서버 주소와 모델명을 입력합니다.
2. 외부 모델의 새 API 키를 입력하고 **키 저장**을 누릅니다. 앱이 현재 Windows 계정의 자격 증명 관리자에 제공자별로 자동 저장하며 다음 실행에 재사용합니다. 별도 보안 저장소 창이나 비밀번호 입력은 필요 없습니다. 화면에는 저장 여부만 표시하고 저장·삭제 후 입력란을 비웁니다. 저장 실패 안내가 나오면 키는 이번 실행의 메모리에서만 사용할 수 있습니다.
3. **과제 검토**에서 과제명과 요약을 입력합니다. 현재 기술사양과 개발목표 사양을 분리하고 성능·단위·용도·예외 관련 근거를 구체적으로 적습니다. 과제명은 필수입니다. 8번 부처 정책 항목에는 실제 부처 세부기준이 필요하며 과제별 기준이 공통 기준보다 우선합니다.
4. **체크리스트** 또는 **국가영향 지표**를 선택합니다. 공통항목 자동 선택 시 국가영향 지표의 선택 항목 가중치는 모두 **1.0**입니다. 안내 문구와 실제 계산에 동일하게 적용합니다. 직접 선택 시 각 가중치 0.8~1.2, 선택 항목 평균 1.0을 검사합니다. 체크리스트는 점수·가중치를 사용하지 않습니다. 마지막 의견 엄격도는 항상 **표준**이며 선택 UI가 없습니다.
5. AI 에이전트는 1개일 때 **AI 기술분야 전문가**, 3개일 때 여기에 **AI 연구보안 전문가·AI 기술사업화 전문가**를 더해 독립 의견을 작성합니다. 고시 자동 대조와 항목 검토 후 결과의 근거·부족정보·에이전트 의견·저장 상태를 확인합니다.
6. 의견서 폴더를 먼저 선택하면 단건 검토 후 HWPX를 저장합니다. 완료 후에도 **검토 결과 → 저장 결과로 의견서 재생성**으로 저장할 수 있습니다. 에이전트별 의견서와 AI 종합 검토의견서를 만들며 AI 작성 표시와 비어 있는 실제 서명란을 포함합니다.

국가영향 지표는 `Σ(가중치×정수점수)/선택항목수`로 에이전트 점수를 계산하고 예정된 전체 에이전트의 평균을 구합니다. 계산 도중 반올림하지 않습니다. 평균 3.5·4.5 구간은 참고 구간이며 법적 정의를 대체하지 않습니다. 정보 부족·잘못된 모델 응답을 임의 3점이나 일반과제로 채우지 않고 `검토필요` 또는 `오류`로 남깁니다.

## 일괄 검토와 결과 보존

입력 `.xlsx`의 `분류대상` 시트(없으면 첫 시트) 첫 행에 `과제명` 열이 필요합니다. 지원 열은 `세부사업명, 과제명, 연구목표, 연구내용, 기대효과, 추가 검토정보, 부처 세부기준, 현재 기술사양, 개발목표 사양`입니다. 빈 과제명, `(예시)`로 시작하는 과제명은 제외하고 같은 과제명은 첫 행만 처리합니다. 중복 열 제목은 거부합니다. 소스 환경에서는 다음 명령으로 합성 예시를 포함한 입력 양식을 만들 수 있습니다.

```powershell
.\.venv_v15\Scripts\python.exe -X utf8 -B -c "from batch_v15 import make_template; make_template('입력양식_v15.xlsx')"
```

**일괄 검토**에서 입력 파일과 다른 결과 경로를 선택하고 실행합니다. 결과 엑셀을 다른 프로그램에서 닫아 둡니다. 결과는 엑셀, `<결과경로>.checkpoint.jsonl`, `<결과경로>.audit.jsonl`, 의견서 폴더에 저장합니다. 엑셀에는 과제 결과와 고시 대조·출처·고정 기준본을 남기며 긴 정보는 이어지는 행에 보존합니다. JSONL에는 schema-2 결과와 실행 당시의 고시 manifest·조항 원문·판정 근거가 보존됩니다.

재개는 과제 내용·옵션·모델·가이드라인·고시 지문이 일치하는 유효한 완료 결과만 재사용합니다. 구버전·손상·불일치 기록은 재사용하지 않습니다. 취소 시 이미 완료한 결과는 보존합니다. 체크포인트·엑셀·감사로그는 각각 별도 파일이므로 일부 저장 실패가 가능하며 화면 경고와 문서 상태를 확인합니다. 잠긴 엑셀이나 권한 문제를 해결한 뒤 다시 실행하거나 재생성합니다. 요청한 1,001개 이상의 과제에서도 의견서 생성을 임의로 끄지 않습니다.

앱 세션에서 보존한 결과로 의견서를 재생성할 때 모델과 현재 고시를 다시 호출하지 않습니다. 배치 결과의 반복 재생성은 다른 과제의 최신 문서 상태를 보존하며 오래된 보고서로 덮어쓰는 요청은 거부합니다. 재시작 후 재개에는 결과 엑셀과 체크포인트 등 원래 결과 묶음을 유지합니다.

총 571개 기록은 지정·통제 검토단위 507개와 공통 정의·주석 64개입니다. 507개 중 수치·정성 조건 구조화 41개, 정성 조건 구조화 49개, 일부 구조화 3개, 원문만 보존한 미해석 414개입니다. **원문 목록 전체 보존은 모든 조건의 자동 의미판정을 지원한다는 뜻이 아닙니다.** 관련 미해석 조건이나 부족한 사양은 `정보 부족`으로 남기고 추가 확인사항을 출력합니다. AI 후보 탐색 완료·후보 없음도 공식 비해당 판정을 의미하지 않습니다.

현재 확인된 사양과 개발목표를 구분해 `충족/불충족/정보 부족` 및 근거·예외를 표시합니다. 목표만 충족하면 ‘목표 달성 시 해당 가능성’입니다. 고시 대조 결과가 연구보안 등급이나 실제 수출허가 여부를 자동 결정하지 않습니다. 상황허가·국가별 제재·실제 수출허가 최종 판단은 범위 밖입니다.

고시를 갱신할 때 공식 확정 통합본문과 전체 별표를 확보하고 발령·시행일, 지정항목·수치·단위·용도·예외·정의를 검수합니다. 새 catalogue ID와 검수 자료를 발행하고 해시·원문 추출·경계·판정 회귀시험을 완료한 뒤 재빌드합니다. 기존 결과에 담긴 과거 고시를 소급 교체하지 않습니다. 파일 하나만 임의 수정하거나 실행 중 자동 내려받기로 바꾸지 않습니다.

## 자료와 API 키

선택한 외부 모델로 과제요약·기술사양·추가 검토정보·부처 기준 및 판단에 필요한 고시 근거를 전달합니다. 외부 전송이 불가능한 자료에는 기관에서 허용한 로컬 모델을 사용하고 서버 주소의 실제 목적지를 확인합니다. 기관별 접근·보관·삭제 기준은 별도로 정해야 합니다. 엑셀·체크포인트·HWPX에는 입력·상세 근거가 남고, 감사로그에는 지문·상태 등 메타데이터를 기록합니다.

키 원문은 소스·설정파일·배포파일·결과·로그에 저장하지 않습니다. 저장 키가 없으면 `ANTHROPIC_API_KEY` 또는 `OPENAI_API_KEY` 환경변수를 사용할 수 있으나 자동 영구 저장하지 않습니다. 앱의 **저장 키 삭제**는 앱 저장소·세션의 키를 지우는 동작이며 환경변수 삭제나 제공자 계정에서의 키 폐기는 별도로 수행합니다. 저장됨 표시는 인증 성공을 의미하지 않습니다.

UI 자산과 글꼴은 로컬 번들에서만 읽습니다. 임의 파일·외부 페이지·새 창·외부 UI 자원 요청을 차단하며 Python 공개 호출은 정해진 9개뿐입니다. 모델 통신은 Python에서 수행합니다. 소스·시험에 실제 키나 민감 과제를 넣지 않습니다.

## 빌드와 자체 검사

```powershell
.\.venv_v15\Scripts\python.exe -X utf8 -B -m unittest discover -s tests -p 'test_v15_packaging.py'
.\.venv_v15\Scripts\python.exe -X utf8 -B .\security_grade_classifier_v15.py --self-check .\build-v15\source-self-check.json
.\.venv_v15\Scripts\python.exe -X utf8 -B -m PyInstaller --noconfirm --workpath .\build-v15 --distpath .\dist-v15 '보안등급분류시뮬레이터_v15.spec'
$check = Start-Process -FilePath '.\dist-v15\보안등급분류시뮬레이터_v15.exe' -ArgumentList '--self-check', '.\build-v15\frozen-self-check.json' -WindowStyle Hidden -PassThru -Wait
$check.ExitCode
Get-Content -LiteralPath '.\build-v15\frozen-self-check.json' -Encoding UTF8
```

자체 검사는 실제 앱의 숨긴 WebView2 창에서 합성 과제·가짜 키 저장소·가짜 모델을 사용합니다. 공개 9개 호출, 단건·배치·HWPX 재생성, 고시·UI 자산, SDK import, 네이티브 IPC 허용목록과 외부 이동 차단을 검사합니다. 실제 키나 유료 모델 API를 사용하지 않습니다. **실제 종료 코드 0과 새 JSON의 `pass:true`를 함께 확인**합니다. EXE 자체 검사는 추가로 `frozen:true`를 확인합니다.

실행 파일은 UI·로컬 글꼴/라이선스·두 파생 HWPX 서식·공식 고시 25개 파일·필수 SDK 및 WebView2/CLR 로더를 포함합니다. 원본 가이드라인 전체, 과거 UI, 실제 키·입력·감사자료, PDF 추출/Playwright/NumPy 등 개발 도구는 포함하지 않습니다. WebView2 네이티브 경계는 pywebview 6.2.1 내부 API를 사용하므로 라이브러리 변경 때 실제 소스·EXE 자체 검사를 다시 수행합니다.

2026-10-23 소스와 최종 EXE 자체 검사가 모두 실제 종료 코드 0·`pass:true`로 통과했습니다. v15 279개·v14 134개, 총 413개 회귀시험이 통과했습니다. WebView2 155.0.4283.62, 고시 571개, OpenAI SDK 2.47.0·Anthropic SDK 1.3.0 import와 실제 UI 흐름을 확인했고 소스/EXE의 UI 자산 해시·고시·SDK 버전이 일치했습니다. 패키징 구성 시험 6개와 SDK 진단을 포함한 통합 영향 시험 8개가 포함됩니다. 실제 EXE 아카이브에서 프로젝트 자산 33개(고시 25개 포함)의 바이트 일치, JS 6개·WebView2Loader 3개·CLR, SDK·메타데이터 및 개발 도구·구형 엔진 제외를 확인했습니다. 검증한 EXE는 42,060,170바이트, SHA256 `f93c9b7ffe464f5cb1aa05d918995d86a20d11455c5ab57bdcced83866b7ea00`입니다. 재빌드하면 실행 파일 해시는 달라질 수 있습니다.

별도 작업 공간의 기존 파일 보존 기준 40개는 변경되지 않았고, 원래 프로젝트와 대조하는 39개도 SHA256이 모두 일치했습니다. 두 위치의 `.gitignore`는 각각 보존하며 동기화하지 않았습니다. 실제 외부 API 인증·모델 응답, Hancom에서의 HWPX 열기/인쇄, 사용자 화면의 125%·150% DPI 점검은 아직 확인하지 않았습니다. 숨긴 앱 창과 헤드리스 화면 검사는 이 수동 점검을 대신하지 않습니다.
