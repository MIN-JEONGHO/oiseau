# 제재통계 자동 산출 프로그램

국가R&D사업 제재통계 엑셀 자동화 도구의 계산 로직을 파이썬으로 옮긴 것입니다.
**원자료만 넣으면 1~9번 결과표가 자동으로 만들어집니다.** 엑셀/LibreOffice 없이 동작하며, `.exe` 로 패키징할 수 있습니다.

```
원자료(입력)  →  전처리  →  1~9 결과시트  →  결과 엑셀 저장
```

원본 엑셀의 수식 계산 결과와 **9개 시트 전부 값이 완전히 일치**함을 (실제 엑셀 수식 엔진으로) 교차검증했습니다.

---

## 1. 준비물

- Python 3.9 이상
- 라이브러리 설치:
  ```
  pip install pandas openpyxl
  ```

## 2. 입력 파일 만들기

`원자료_입력템플릿.xlsx` 의 **원자료** 시트에 데이터를 채워 넣으세요. (컬럼 순서/이름 유지)

| 컬럼 | 설명 |
|---|---|
| 처분연도 | 연도(숫자) |
| 제재유형구분 | `참여제한` / `환수금` / `제재부가금` |
| 연구수행주체 | 원본 기관유형 |
| 연구수행주체(정제) | 정제값(있으면 이 값을 우선 사용, 없으면 원본 사용) |
| 제재사유(기본법) | 예: `01. 연구결과불량` |
| 제재사유(혁신법) | 예: `12. 연구과정 및 결과 불량` |
| 미납금액 / 대상금액(원) / 납부금액(원) | 금액(원) |
| 소관부처 | 예: `과학기술정보통신부` |
| 제재ID | 건수 집계 기준(값이 있으면 1건) |

CSV 도 동일한 컬럼이면 그대로 사용할 수 있습니다.

## 3. 실행

```bash
# 기본: 결과가 입력파일과 같은 폴더에 "제재통계_결과.xlsx" 로 저장됨
python sanction_stats.py 원자료.xlsx

# 출력 경로 지정
python sanction_stats.py 원자료.xlsx -o 결과.xlsx

# CSV 입력 / 시작연도 변경(기본 2017, 14개 연도)
python sanction_stats.py 원자료.csv -o 결과.xlsx --base-year 2017
```

실행이 끝나면 결과 엑셀에 시트 `1`~`9` 가 만들어집니다.

| 시트 | 내용 | 단위 |
|---|---|---|
| 1 | 참여제한 · 제재사유별 | 건 |
| 2 | 참여제한 · 기관유형별 | 건 |
| 3 | 참여제한 · 부처별 | 건 |
| 4 | 환수금 · 제재사유별 | 억원 |
| 5 | 환수금 · 기관유형별 | 억원 |
| 6 | 환수금 · 부처별 | 억원 |
| 7 | 제재부가금 · 제재사유별 | 억원 |
| 8 | 제재부가금 · 기관유형별 | 억원 |
| 9 | 제재부가금 · 부처별 | 억원 |

> 실행 후 "검증 불일치 시트" 경고가 나오면, 매핑 목록에 없는 제재사유·기관유형·부처명이
> 원자료에 들어있다는 뜻입니다(그 데이터가 결과에서 누락됨). 아래 매핑 표를 확인하세요.

## 4. exe 로 만들기 (배포용)

윈도우에서 파이썬 없이 실행하려면 PyInstaller 로 단독 실행파일을 만듭니다.

```bash
pip install pyinstaller
pyinstaller --onefile --name 제재통계 sanction_stats.py
```

- 생성물: `dist/제재통계.exe`
- 사용법 세 가지:
  1. **드래그&드롭**: 원자료 파일을 `제재통계.exe` 위로 끌어다 놓기
  2. **더블클릭**: 실행 후 원자료 파일 경로를 입력
  3. **명령창**: `제재통계.exe 원자료.xlsx -o 결과.xlsx`

결과 파일은 원자료와 같은 폴더에 `제재통계_결과.xlsx` 로 저장됩니다.

> 참고: exe 는 만든 OS(윈도우/맥)에서만 동작합니다. 윈도우 배포용 exe 는 윈도우에서 빌드하세요.

## 5. 집계·매핑 규칙 (원본과 동일)

- **전처리**: 연구수행주체(정제)가 있으면 그 값, 없으면 원본 사용 / 금액 0·오류는 빈칸 처리 /
  `건수 = 제재ID 가 있으면 1`
- **건수 시트(1~3)**: 제재ID 건수 합계
- **금액 시트(4~9)**: 대상금액(원) 합계 ÷ 1억 (억원)
- **합계 열**: 표시 연도 구간의 합만 계산(구간 밖 연도 제외)

**제재사유(기본법+혁신법) 통합** — 9개 항목으로 묶음.
(시트 7만 5번째 항목이 `환수금 미납`이 아니라 `제재부가금 미납` 입니다.)

**기관유형 통합**: 대학 / 대기업 / 중견기업 / 중소기업 / 출연연(=출연연구소) /
국공립연구소(+정부부처) / 기타(빈값·기타)

**부처 통합(명칭 변경 이력 병합)**: 과학기술정보통신부(+미래창조과학부),
방송미디어통신위원회(+방송통신위원회), 소방청(+소방방재청), 중소벤처기업부(+중소기업청) 등
