# 고시해당 판정 프로그램 (화면 이름: 연구보안 등급분류 분류기준(고시) 검토, 옛 이름: 고시 수준 검토)

- **현재 버전**: `고시판정v1/`. 작업 지침은 그 폴더의 `AGENTS.md`, 사용·판정 규칙·확인 범위는 `README.md`.
- 고시 자료는 보안등급분류 시뮬레이터 `resources_v16/notices`의 바이트 복사본이고, 기준값 표는 개발 때 한 번 만들어 고정한다. 고시가 개정되면 시뮬레이터 갱신 뒤 새 버전 폴더에서 다시 복사해 표를 다시 만든다.
