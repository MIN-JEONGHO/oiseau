# 연구보안 등급분류 분류기준(고시) 검토 (고시판정v1, 프로그램 표기 1.4.2)

연구개발과제의 **최종 연구목표 수치**를 세 고시(국가첨단전략기술, 국가핵심기술, 전략물자수출입고시 별표 2 이중용도·별표 3 군용)의 **숫자 기준**과 대조해, 고시 수준을 **초과**하는지, **근접**(기준에 10% 이내로 못 미침)하는지, **미달**인지 알려 주는 Windows 도구입니다.

> 이 결과는 고시 수치 기준과의 **참고 대조**이며 고시 해당 여부의 공식 판정이 아닙니다. 상황허가·수출허가 판단, 보안등급 결정을 대신하지 않습니다.

1.3.0부터 결과는 먼저 **간단한 결과**로 보입니다. 1.4.0부터 간단한 결과는 초과·근접 중심입니다 — 세 판정(고시 사양 초과 / 고시 사양 근접 / 고시 사양 미달)과 과제 사유, 초과·근접한 사양마다 한 줄(아래 1.4.0과 '간단한 결과' 절. 1.3.x까지는 셋째 판정이 `사양 미달 또는 무관`이었고 조항마다 한 줄이었습니다). 조항별 상세는 화면의 접힌 '상세 보기'와 결과 엑셀 `고시 조항별 상세` 시트에 그대로 남습니다.

1.3.1은 첨부 목표 발췌를 넣은 개별 검토가 `최종목표 사양 추출: 재요청 뒤에도 응답 모양이 틀림: JSON 객체 하나를 받지 못함`으로 끝난 일이 있어, 최종목표 사양 추출(AI 1단계)을 두 가지 바꾼 판입니다(원인은 확인되지 않음 — 아래 '확인 범위').

- **수치 위치는 프로그램이 찾습니다**: AI에게 수치마다 글자 위치를 세어 답하라고 하지 않습니다. 프로그램이 AI가 적은 인용을 그 수치를 뽑은 글에서 글자 그대로 찾아 위치를 정하고, 그 글에 그대로 없으면 지금처럼 버린 뒤 처리내역에 남깁니다(사유 `인용이 글에 없음`).
- **출력 한도**(AI 세 단계 모두): 모델 출력 한도를 Anthropic(Claude)·OpenAI는 32,000토큰으로 늘렸습니다. OpenAI에는 32,000으로 실제 요청해 보지 않았습니다(모델의 출력 상한이 그보다 작으면 요청 오류가 날 수 있음, 미확인). 로컬 AI(Ollama·LM Studio)는 8,000토큰 그대로입니다. 요청당 대기 시간(600초)·재시도는 같습니다.
- 판정 계산·간단한 결과·결과 엑셀·화면·AI에 보내는 자료의 종류·요청 수는 1.3.0과 같습니다.

- **Wh 계열 환산**: Wh·kWh·MWh·GWh를 J 기준 3,600배로 둡니다(1 Wh = 3,600 J). 1.3.2까지는 1 Wh를 1 J로 두어 J 계열로 환산하면 3,600배 작게 나왔습니다(예: `5 Wh → kJ`가 0.005, 고친 뒤 18. `1 kWh → MJ`가 0.001, 고친 뒤 3.6). 목표 단위가 Wh 계열이고 기준이 J 계열이면 이상·초과 기준은 미달 쪽으로, 이하·미만 기준은 초과 쪽으로 틀릴 수 있었습니다. Wh끼리(kWh ↔ Wh)의 환산과 에너지밀도(Wh/kg 등 따로 둔 종류)는 전과 같습니다.
- **정확한 분수 환산**: 환산 인자를 정확한 분수로 다룹니다. 3600·60으로 나누는 단위의 배수를 끊긴 소수 대신 `분자/분모`로 적었고, 환산한 값이 유한 소수이면 정확한 값을(끝의 0 없이), 끝나지 않는 소수이면 계산 정밀도 28자리에서 반올림한 값을 씁니다. 그래서 환산하면 기준값과 정확히 같은 목표가 같은 값으로 비교됩니다.
  - 예: 목표 `2160 km/h`와 기준 '600 m/s 초과'는 1.3.2까지 `초과`(환산 600.0000000000000480)였고 1.3.3부터 `근접`(환산 600 — 초과 기준에서 같은 값은 충족이 아니라 근접)입니다. 목표 `720 arcsec`와 기준 '0.2° 이하'는 `근접`에서 `초과`(충족)로 바뀝니다. `180 arcsec` ↔ 0.05° 이하, `21600 °/h` ↔ 6 °/s 이하, `55.56 km/h` ↔ 30 kn 초과도 같습니다.
  - 배수 표기가 바뀐 단위는 16개입니다: Wh·kWh·MWh·GWh(3600배), km/h·kn·m3/min·m3/h·L/min·L/h·cm3/min·arcsec·°/h·Torr(분자/분모), psi(lbf/in² 정의대로), hp(끊긴 자리 보충). rad·mrad·μrad는 원주율이 들어가 어림값 그대로입니다. 단위 수(244개)·종류·별칭은 그대로입니다.
  - 고치기 전과 뒤를 환산할 수 있는 모든 단위 쌍 × 값 9개(9,810건)로 견주었습니다. 8,046건은 같고, 792건은 Wh 계열과 다른 에너지 단위 사이(정확히 3,600배), 972건은 배수 표기가 바뀐 단위가 낀 쌍에서 상대 차이 1조분의 1 미만(최대 약 4.1e-13)입니다. 그 밖의 차이는 없습니다.
  - 전의 판으로 이미 낸 결과 가운데 목표 단위가 Wh 계열이거나 환산한 값이 기준값과 정확히 같았던 과제는 1.3.3으로 다시 돌려 봅니다.

## 간단한 결과 (1.4.0 — 초과·근접 중심)

판정 계산은 1.2.0과 같습니다. 간단한 결과는 판정 엔진의 값을 세 이름으로 바꿔 보이고, 숫자로 비교된 조항을 초과·근접 조항과 미달 조항으로 나눠 보입니다. 판정 이름·과제 사유·과제 묶음·사유 문장·건수·종합 건수와 과제 순서는 모두 프로그램(`brief.py`)이 만들며 화면과 결과 엑셀은 받은 글을 그대로 보입니다(AI 글을 쓰지 않음, 화면 스크립트는 세거나 묶지 않음). 1.3.0~1.3.3의 모양(판정 이름 `사양 미달 또는 무관`·`최종목표 수치 없음`, 한 조항 한 줄의 '해당 조항', 결과마다 붙던 공통 안내 세 줄, 과제 한 줄씩의 일괄 표)은 1.4.0에서 아래로 바뀌었습니다.

- **세 판정**: `고시 사양 초과`(초과) / `고시 사양 근접`(근접) / `고시 사양 미달`(미달·수치 판정 없음). 고시별 결과와 종합 결과(고른 고시 중 가장 높은 것), 조항 판정, 사양 비교 결과에 씁니다. 고르지 않은 고시는 `대조 안 함(선택 제외)`. 화면 '상세 보기'와 결과 엑셀 `고시 조항별 상세`·`처리내역` 시트에는 판정 엔진의 내부 값(초과·근접·미달·수치 판정 없음·판정 안 함(상태 참고) 등)과 과제 상태가 그대로 나옵니다.
- **과제 상태별**: 완료 → 위 대응. 관련 고시 항목 없음·목표 수치 없음 → 고른 고시·종합 모두 `고시 사양 미달`. 오류 → `오류`(오류 사유는 따로 보임). 취소 → `취소`. 오류·취소 과제는 판정된 것이 아니므로 어떤 건수에서도 `고시 사양 미달`에 넣지 않습니다. 대응표에 없는 판정 값이 오면 다른 이름으로 바꾸지 않고 그 과제를 오류로 끝냅니다.
- **과제 사유**(종합 결과 옆 한 줄, 정해진 틀)

  | 경우 | 사유 |
  |---|---|
  | 종합이 초과·근접 | 첫 초과·근접 조항의 `{고시 이름} {통제번호} {고시 조항명}`(통제번호가 없으면 뺌). 초과·근접 조항이 더 있으면 끝에 ` 외 N건` |
  | 완료, 숫자로 비교된 조항이 있고 모두 미달 | `기준에 못 미침` |
  | 완료, 숫자로 비교된 조항이 없음 | `사양이 겹치는 고시 조항 없음` |
  | 관련 고시 항목 없음 | `관련 고시 조항 없음` |
  | 목표 수치 없음 | `최종목표 수치 없음` |
  | 오류·취소 | 빈 글(오류 사유는 따로 보임) |

- **과제 묶음**: 종합이 초과·근접이면 **중점**, 미달이면 **그 밖**, 오류·취소이면 **판정 못 함**. 일괄 화면의 묶음과 종합 건수가 이것을 씁니다.
- **조항 나누기**: 조항 판정이 초과·근접·미달인 조항, 즉 최종목표 사양과 고시 기준 사양이 매핑되어 실제로 비교된 조항만 넣습니다. 조항 판정이 초과·근접이면 **초과·근접 조항**, 미달이면 **미달 조항**입니다. '수치 비교 불가'·'수치 기준 없음(관련 분야)' 조항은 감춥니다(상세에는 남음). 완료가 아닌 과제는 둘 다 빈 목록입니다.
  - 순서: 초과·근접 조항은 판정(초과 → 근접) → 고시(국가첨단전략기술 → 국가핵심기술 → 전략물자(이중용도) → 전략물자(군용)) → 판정 기록의 조항 순서. 미달 조항은 고시 → 판정 기록의 조항 순서.
- **초과·근접 조항의 사양 줄 — 사양마다 한 줄**: 그 조항의 판정을 정한 갈래를 갈래 순서대로, 갈래 안 기준을 기준 순서대로 보면서, 기준마다 숫자로 비교된 것 중 가장 높은 판정의 비교 하나를 한 줄로 보입니다. 줄마다 그 비교의 판정(`고시 사양 초과` 또는 `고시 사양 근접`)이 붙습니다. 예: 근접 조항 안에서 한 사양은 충족하고 한 사양은 근접이면 줄이 둘입니다(`고시 사양 초과`·`기준보다 N% 초과`와 `고시 사양 근접`·`기준보다 N% 미달`). 숫자로 비교된 것이 없는 기준은 줄이 없고 확인 표시 `일부 수치만 비교`로 드러납니다. 판정을 정하지 않은 갈래의 비교와 같은 기준의 더 낮은 비교는 줄로 만들지 않으며(`고시 조항별 상세`에 그대로 있음), ` · 외 N건`을 붙이지 않습니다. 이렇게 고른 줄이 미달이면 규칙이 깨진 것이므로 조용히 넣거나 빼지 않고 그 과제를 오류로 끝냅니다.
- **미달 조항의 사양 줄 — 한 줄**: 1.3.x의 '사유에 쓰는 비교 하나' 규칙 그대로입니다(판정을 정한 갈래의 기준마다 가장 높은 판정의 비교를 차례로 보고, 그 판정이 조항 판정과 같은 첫 비교). 같은 조항에 숫자로 비교된 다른 비교가 있으면 사유 문장 끝에 ` · 외 N건`을 붙입니다.
- **사유 문장**(한 문장, 정해진 틀): `{입력 위치} "{입력 인용}" ↔ 기준 {물리량} {기준값}{단위} {비교어}, {차이}`. 단위를 환산해 비교했으면 기준 뒤에 `(환산 {값} {기준 단위})`. 기준값은 지수 표기 없이 세 자리마다 쉼표, 소수 끝의 0을 지웁니다(`3,000,000`·`500`·`0.95`). 환산한 값은 같은 표기에 유효숫자 4자리로 줄이고, 줄여서 값이 달라졌으면 `약`을 붙입니다(예: 목표 30 m/s, 기준 100 km/h → `(환산 약 108 km/h)`). 판정 계산과 상세 보기·상세 시트의 환산 값은 줄이지 않습니다. 최종목표 쪽은 입력 원문 글 그대로입니다. 화면에서는 인용이 80자보다 길면 앞 80자 뒤에 `…`, 결과 엑셀에는 전부 넣습니다. 사유 문장 끝에 확인 표시는 붙이지 않습니다(조항에 따로 보임).
  - 차이: 충족이면 `기준보다 N% 초과`(기준값 0이면 `기준 초과`), 못 미치면 `기준보다 N% 미달`, 초과·미만 기준에서 목표가 기준값과 같으면 `기준값과 같음(같은 값은 초과 아님)`. 이상·초과·이하·미만 어느 방향이든 '초과'는 고시 사양을 넘어섰다는 뜻입니다(이하·미만 기준에서는 값이 더 작은 쪽). 1.4.2부터의 문구이며 1.4.1까지는 `기준 충족(여유 N%)`·`기준 충족`·`기준에 N% 못 미침`·`기준값과 같음(같은 값은 충족 아님)`였습니다. N은 기존 차이 %와 같은 반올림(소수 첫째 자리)입니다.
- **확인 표시**(초과·근접 조항과 미달 조항 모두, 조항마다 `확인: a · b`): `추가 확인 조건` · `갈래 확인 필요` · `매핑 확인 필요` · `범위 목표` · `일부 수치만 비교` · `입력 간 목표값 불일치` · `기준값 채택 실패(원문 확인 필요)` 일곱 가지를 조항 기록의 순서대로 보입니다. `추가 확인 조건`은 용도·양산 목적·예외 같은 숫자 외 조건이 그 조항에 있다는 뜻입니다(원문은 상세 보기와 `고시 조항별 상세` 시트의 `추가 확인 조건 원문`에). `AI가 읽은 기준값(원문 확인 필요)`은 거의 모든 조항에 해당해 앞쪽 결과에는 보이지 않고, 상세 보기와 `고시 조항별 상세` 시트의 `확인 표시`에 조항마다 나옵니다.
- **추가 검토 필요**(판정이 아니며 고시별·종합 결과를 바꾸지 않음. 원문 확인 권고): 감춘 조항 중 AI가 관련 조항으로 고른 것이면서 다음 하나에 맞는 조항만 남깁니다.
  - 전략물자(이중용도) 조항이면 모두 — `이중용도 관련(AI 선별)`.
  - 국가첨단전략기술·국가핵심기술·전략물자(군용) 조항은 AI가 선별에서 '세부 기술 일치'로 답했고, **그리고** PC 안 의미 검색에서 같은 고시 안 상위 5위 안에 들 때만 — `세부 기술 일치(AI·검색)`.
  - 비교하지 못한 이유를 함께 보입니다: `숫자 기준 없음` / `맞는 최종목표 수치 없음` / `단위 비교 불가` / `기준값 0 비교 불가` / `기준값 채택 실패(원문 확인 필요)`.
  - 1.4.0부터 중점 목록과 섞지 않고 뒤로 물려 보입니다(개별은 접힌 묶음, 일괄은 과제마다 건수, 결과 엑셀은 `과제별 검토 결과`의 `추가 검토 필요` 칸).
- **PC 안 의미 검색**: 검색 글은 연구개발과제명 + 최종목표 + 연구개발내용(최종목표·연구개발내용이 모두 비었으면 연구개발과제명 + 목표 발췌)입니다. 03 고시 검색과 같은 내장 모델·조항 벡터로 같은 고시 안 실제 검토 항목의 순위를 매기며 관련어 사전은 쓰지 않습니다. 검색 글은 PC 밖으로 나가지 않고 파일·결과·로그에 남지 않으며, 유사도 숫자는 보이지 않습니다. 따질 조항이 있을 때만 검색합니다. 모델을 쓸 수 없으면 세부 기술 일치를 확인하지 않고 안내 `의미 검색을 쓸 수 없어 세부 기술 일치 확인 안 함`을 보입니다(관련어 사전으로 대신하지 않음, 이중용도 규칙은 그대로).
- **건수**(과제마다): 초과 조항 수, 근접 조항 수, 미달 조항 수, 추가 검토 필요 수, 간단한 결과에 넣지 않은 관련 조항 수, 세부 기술 일치로 답했지만 남기지 않은 조항 수. 뒤의 둘(감춘 것의 건수)은 상세 보기와 `처리내역`에 남습니다.
- **종합 건수**(실행 한 번): 종합이 초과·근접·미달인 과제 수를 `고시 사양 초과 n건 · 고시 사양 근접 n건 · 고시 사양 미달 n건`으로 보이고, 오류·취소 과제가 있으면 `오류·취소(판정 없음) n건`을 더합니다(0이면 보이지 않음). `고시 사양 미달`에는 완료·미달, 완료·숫자로 비교된 조항 없음, 관련 고시 항목 없음, 목표 수치 없음 과제가 들어갑니다. 네 수의 합은 처리한 과제 수(건수 줄의 `전체`)와 같습니다.
- **안내 줄**(있을 때만): `의미 검색을 쓸 수 없어 세부 기술 일치 확인 안 함`, 그리고 버린 최종목표 사양·매핑과 선택 칸 경고가 0보다 크면 그 건수(`버린 최종목표 사양·매핑 N건 · 선택 칸 경고 N건 — 상세 보기에서 확인`). 1.3.x까지의 `AI가 고른 관련 고시 조항 없음`은 과제 사유 `관련 고시 조항 없음`과 겹쳐 없앴습니다. 일괄 검토에는 실행 전체의 안내 줄 `선택 칸 경고 N건 — 상세 보기·처리내역(숨김 시트)에서 확인`이 있습니다.
- **공통 안내는 없습니다**(1.4.0): 1.3.x까지 결과마다 붙던 세 줄을 결과 화면과 결과 엑셀에서 뺐습니다. 화면 맨 아래의 한 줄 `이 결과는 고시 수치 기준과의 참고 대조이며 고시 해당 여부의 공식 판정이 아님.`은 늘 보입니다.

  3. **초과·근접 고시 조항**(펼쳐 있음) — 조항마다 조항 판정·고시 이름·통제번호·고시 조항명, 확인 표시가 있으면 `확인: a · b`, 그 아래 사양 줄마다 사유 문장, '고시 검색에서 열기'. 없으면 `고시 사양을 초과하거나 근접한 조항 없음`(오류·취소면 이 묶음이 보이지 않음)

  6. **상세 보기**(접혀 있음) — 1.2.0 결과 화면 전부와 감춘 것의 건수(내용은 1.3.3과 같음)

  1. 건수 줄(`전체 n · 완료 n · 목표 수치 없음 n · 관련 고시 항목 없음 n · 오류 n · 취소 n · 제외 행 n · 빈 행(모든 칸이 빈 행) n · 선택 칸 경고 n`)
  2. **종합 건수** — 판정별로 색이 다른 칸. 1.4.1부터 단추입니다: 누르면 아래 4~6 대신 그 결과의 과제만 과제 카드로 보이고(제목은 단추 글, 옆에 `전체 보기`), 같은 단추를 다시 누르거나 `전체 보기`를 누르면 4~6으로 돌아옵니다. 그 아래에 안내 글 `건수를 누르면 그 결과의 과제만 보임. 다시 누르거나 '전체 보기'를 누르면 처음 화면`
  3. 안내 줄(있을 때만)
  4. **중점 검토 과제 (초과·근접 n건)** — 종합 초과 → 종합 근접, 같으면 입력 순. 과제마다 종합 판정·`N행`·연구개발과제명, 추가 검토 필요가 있으면 `추가 검토 n건`, 그 과제의 초과·근접 조항 전부(조항 판정·고시 이름·통제번호·고시 조항명, 확인 표시, 사양 줄마다 사유 문장). 미달 조항과 추가 검토 필요 목록은 여기 보이지 않습니다. 중점 과제가 없으면 `고시 사양을 초과하거나 근접한 과제 없음`
  5. **판정하지 못한 과제 (오류 n · 취소 n)** — 오류·취소 과제가 있을 때만, 접지 않고. 표: `입력 행 번호`·`연구개발과제명`·`상태`·`오류 사유`

  7. 엑셀 안내 한 줄 `초과·근접한 사양은 결과 엑셀 '초과·근접 조항' 시트, 모든 비교는 '고시 조항별 상세' 시트에서 확인`
  8. **상세 보기**(접혀 있음) — 1.2.0 일괄 표(내용은 1.3.3과 같음)

| 2 | `과제별 검토 결과` | 보임 | 모든 과제 한 줄씩(입력 순). 표 아래에 실행 정보 줄 |

| 4 | `처리내역` | **숨김** | 실행 기록(`항목`·`값`). 1.3.3의 줄에서 마지막 `참고` 줄만 뺌 |

- **`초과·근접 조항`의 열**: `입력 행 번호`, `연구개발과제명`, `판정`(조항 판정), `검토 대상 고시`, `통제번호`, `고시 조항명`, `사양 비교 결과`(그 줄의 판정), `최종목표 사양`, `고시 기준 사양`, `차이`, `확인 표시`(그 조항의 확인 표시를 `; `로 — 같은 조항의 줄마다 같은 값), `사유`(자르지 않은 사유 문장). 줄 순서는 과제(종합 초과 → 종합 근접, 같으면 입력 순) → 조항 → 사양 줄. 줄이 하나도 없으면 머리글 아래 첫 칸에 `고시 사양을 초과하거나 근접한 조항 없음` 한 줄. 미달 조항과 추가 검토 필요는 이 시트에 없습니다.
- **`과제별 검토 결과`의 열**: `입력 행 번호`(개별 검토는 빈칸), `연구개발과제명`, `판정`(종합 결과), `사유`(과제 사유), `국가첨단전략기술`, `국가핵심기술`, `전략물자(이중용도)`, `전략물자(군용)`(고시별 결과), `초과 조항 수`, `근접 조항 수`(숫자), `추가 검토 필요`(조항마다 `{고시 이름} {통제번호} {고시 조항명} — {남긴 이유}, {비교하지 못한 이유}`를 줄바꿈으로, 없으면 빈칸), `연구개발단계`, `정부지원연구개발비(백만원)`(숫자), `입력 정보`, `상태`, `오류 사유`, `안내`(그 과제의 안내 줄을 `; `로). 1.3.x까지의 `미달 조항 수`·`수치 비교 불가 조항 수`·`수치 기준 없음 조항 수`·`확인 표시 조항 수`·`참고` 열은 없앴습니다(건수는 화면 상세 보기에, 조항별 내용은 `고시 조항별 상세`에 있음).
  - 표 아래 빈 줄 하나 뒤에 **실행 정보 줄**(첫 칸 항목 이름, 둘째 칸 값): `실행 일시`, `프로그램 버전`(`연구보안 등급분류 분류기준(고시) 검토 1.4.2`), `AI 모델`(`{제공자} · {모델}`, 없는 쪽은 `(없음)`), `종합 결과`(종합 건수 한 줄), `검토에서 빠진 행`(`n건` — 개별 검토는 `0건`), 그리고 빠진 행마다 `검토에서 빠진 행` 한 줄(`{N}행: {사유}`에 값이 있으면 ` — {값}`).
- **`처리내역`(숨김 시트) 보는 법**: 엑셀에서 아래 시트 탭을 오른쪽 클릭 → '숨기기 취소'(시트 숨기기 취소)에서 `처리내역`을 고르면 보입니다. 보통 숨김이라 암호나 다른 도구가 필요 없습니다. 기준본 이름·지문, 고시 기준 사양 표 지문, AI 제공자·모델, 근접 기준, 검토 대상 고시, 제외 행, 빈 행 건수, 선택 칸 경고, 버린 최종목표 사양·매핑과 사유, 파일 읽기 경고, 오류·취소 건수, AI 호출 수, 의미 검색 줄이 1.3.3과 같이 들어 있습니다. 일괄 검토의 버린 최종목표 사양·매핑과 사유는 화면에 건수만 나오므로 이 시트에서 봅니다. `해당 조항 수 합계`는 초과·근접·미달 조항 수의 합입니다.
- 공통 안내 세 줄과 `참고` 열·줄은 결과 엑셀 어디에도 없습니다(1.4.0).
- **행 높이**(1.4.1): 모든 시트의 행은 한 줄 높이(16.5)로 고정입니다. 여러 줄인 칸(`추가 검토 필요`)은 첫 줄만 보이며 값은 그대로입니다. 전체를 보려면 그 셀을 고르거나(수식 입력줄) 행 높이를 늘립니다.

## 고시 검색 (03 탭, 1.2.0부터)

AI 없이 PC 안에서만 고시 조항을 찾습니다. 검색어와 고시 글은 어디로도 보내지 않고, 검색어를 기록하지 않습니다.

- **대상**: 실제 검토 항목 507개(공통 정의·주석 제외). 통제번호·조항 제목·분야·원문(국문·영문)·고시 기준 사양 물리량 이름을 찾습니다. 검토 대상 고시를 전체 또는 하나로 고를 수 있습니다.
- **두 묶음**: '검색 결과'(검색어·관련어가 글자로 들어 있거나 철자가 비슷한 조항)와 '비슷한 뜻(참고)'(의미 유사도로만 찾은 조항, 맞지 않는 것이 섞일 수 있음). 숫자 점수는 보이지 않고 찾은 이유(검색어 일치 / 같은 말 / 관련어(한 단계·두 단계) / 글자 비슷 / 뜻 비슷 / 통제번호 일치 / 본문에서 언급 / 전체 목록)를 보입니다.
- **펼치면**: 원문 전체(찾은 낱말 강조)와 고시 기준 사양 목록(AI가 읽은 기준값 표시, 추가 확인 조건, 채택 실패, 수치 기준 없음 안내).
- **관련어 사전**(`resources/search_dictionary.json`): 같은 말 묶음 433개(낱말 1,287개)와 위·아래 관계 265개. 개발 때 AI가 고시 원문에서 만들었고 낱말마다 원문 근거를 검사했으며, **2026-11-06 사용자 검수 완료**. 검색어를 같은 말 → 위·아래 한 단계 → 두 단계(형제 분야까지)로 넓힙니다. 사전은 내장만 씁니다(고치려면 `tools/synonyms/*.json`을 고쳐 다시 빌드).
- **의미 유사**: 공개 다국어 정적 단어 벡터 모델 potion-multilingual-128M(MIT, 리비전 `73908c3`)을 낱말을 줄이고 int8로 바꿔 넣었습니다(`resources/search_model/`, 출처·해시·라이선스는 `MODEL_INFO.json`). 조항 벡터는 미리 계산해 두었습니다(`resources/search_vectors.*`). 실행 라이브러리는 numpy·tokenizers뿐이고 인터넷에 접속하지 않습니다. 모델을 불러오지 못하면 '의미 유사 검색 꺼짐' 안내를 띄우고 관련어·글자 유사로 계속 찾습니다.

## 판정 규칙 요약

- **고시 기준 사양 표**(파일 `resources/thresholds.json`): 고시 507개 실제 항목의 숫자 기준을 개발 때 한 번 읽어 `resources/thresholds.json`으로 고정했습니다(기준값 2,056개 = 시뮬레이터 고시 자료에 정리돼 있던 57개 + 원문에서 AI가 읽은 1,999개). 원문에서 읽은 기준값은 상세 보기와 결과 엑셀 `고시 조항별 상세` 시트에 조항마다 언제나 **'AI가 읽은 기준값(원문 확인 필요)'** 로 표시됩니다. 앞쪽 결과(화면의 상세 보기 밖, 결과 엑셀 `초과·근접 조항`·`과제별 검토 결과` 시트)에는 이 표시를 조항마다 붙이지 않습니다(거의 모든 조항에 해당하기 때문. 1.3.x까지는 공통 안내로 한 번 보였고 1.4.0에서 그 안내를 뺐습니다). 검수용 엑셀은 `tools/output/기준값_검수.xlsx`입니다(표를 다시 만들 때 생성).
- **사양 비교**: 최종목표 사양 V, 고시 기준 사양 T. 기준을 충족하면(이상·이하는 같은 값 포함) **초과**. 못 미친 차이가 기준값의 10% 이하이면 **근접**, 넘으면 **미달**. 범위 목표(예: 2,800~3,200)는 기준을 넘기에 유리한 끝값으로 비교하고 '범위 목표' 표시.
- **단위 환산**: 목표 단위와 기준 단위가 같은 글자이면 그대로, 다르면 같은 종류이고 환산표에 있을 때만 환산해 비교합니다(온도·비율은 환산하지 않음). 1.3.3부터 환산은 정확한 분수로 계산해, 환산한 값이 기준값과 정확히 같으면 같은 값으로 비교됩니다(예: 2160 km/h = 600 m/s). Wh 계열은 1 Wh = 3,600 J입니다. rad 계열은 원주율 때문에 어림값입니다.
- **조항 검토 결과**: 한 갈래 안 여러 고시 기준(AND)은 가장 낮은 판정, 갈래 사이(OR)는 AI가 고른 갈래 또는 가장 높은 판정('갈래 확인 필요' 표시). 일부 기준만 비교했으면 '일부 수치만 비교'와 빠진 기준을 표시.
- **숫자 외 조건**(용도·양산 목적·예외·'특별히 설계된')은 판정을 바꾸지 않고 **'추가 확인 조건'** 으로 원문과 함께 보입니다(상세 보기·`고시 조항별 상세` 시트에 조항마다 원문과 함께. 1.4.0부터 앞쪽 결과에서는 그 조항의 확인 표시 `추가 확인 조건`으로 — 1.3.x까지는 공통 안내로 한 번 보였습니다). 숫자 기준이 없는 관련 항목은 '수치 기준 없음(관련 분야)'.
- **AI가 하는 일**: 최종목표 사양 추출, 관련 고시 조항 선별(1.3.0부터 조항마다 '세부 기술 일치' 여부도 답함 — 과제 기술이 조항명의 바로 그 세부 기술이면 참, 같은 넓은 분야일 뿐이면 거짓. '추가 검토 필요'에만 쓰고 판정·조항 목록(초과·근접 조항, 미달 조항)에는 쓰지 않음), 최종목표 사양과 고시 기준 사양 매핑. **초과·근접·미달은 프로그램이 계산**합니다. 추출한 수치는 AI가 적은 인용이 그 수치를 뽑은 글에 글자 그대로 있는지 프로그램이 찾아 확인하고(1.3.1부터 위치도 프로그램이 정함), 그 글에 그대로 없는 것은 버린 뒤 처리내역(1.4.0부터 숨김 시트)에 남깁니다.
- **과제 상태**: 완료 / 목표 수치 없음(대조 안 함) / 관련 고시 항목 없음(공인 비해당 아님) / 오류 / 취소.

## AI에 보내는 것

연구개발과제명, 최종목표, 연구개발내용, 활용계획 및 기대효과, 사용자가 확인한 목표 발췌 글, 고시 조항 색인과 관련 고시 조항의 기준 기록·원문, 고정 지시문. 연구개발단계·정부지원연구개발비, 첨부파일 자체·발췌하지 않은 글·결과 엑셀·키는 보내지 않습니다. 1.3.0에서 선별 응답에 '세부 기술 일치' 칸이 하나 늘었을 뿐 보내는 것·요청 수·묶음 크기는 같습니다. 1.3.1에서는 추출 지시문에서 글자 위치를 세라는 요구를 빼고 받는 수치 칸이 여덟 개로 줄었을 뿐 보내는 자료의 종류·요청 수·묶음 크기·재요청 규칙은 같습니다. 최종목표 수치는 네 글(최종목표·연구개발내용·활용계획 및 기대효과·목표 발췌) 모두에서 뽑고, 같은 고시 기준에 서로 다른 값이 있으면 더 높은 판정을 쓰고 '입력 간 목표값 불일치'를 표시합니다.

## 기준값 표 다시 만들기

고시가 개정되면 시뮬레이터가 새 고시 자료를 낸 뒤 **새 버전 폴더**에서 `resources/notices`를 다시 복사하고 추출 파일을 고쳐 표를 다시 만듭니다.

```powershell
python tools/build_threshold_table.py --check tools/extracted/<파일>.json   # 파일 하나 검사(쓰기 없음)
python tools/build_threshold_table.py                                       # 전체 생성 → resources/thresholds.json, tools/output/기준값_검수.xlsx
```

## 알려진 한계

- 원문의 지수 표기(`5×103`처럼 평문화됨), 음수 기준, 수식·표로만 주어진 조건, 비교어가 없는 범위 표기(`75~650 mm`)는 기준값으로 넣지 않고 '추가 확인 조건'으로만 보입니다.
- 가속도 단위 `g`는 질량 그램으로 해석됩니다. 단위 종류를 모르는 기준값 45개(16종: 개·축·단·사이클·레벨 등)는 같은 글자일 때만 비교됩니다.
- 한 과제에 첨부파일은 한 개, 일괄 검토에서는 첨부를 받지 않습니다. 예전 HWP·스캔 PDF는 지원하지 않습니다. 일괄 검토 이어하기는 없습니다.
- 1.0.0의 일괄 입력 양식(`과제번호`·`과제명`·`과제요약`)은 읽지 못합니다(필수 머리글 없음 오류). 새 양식을 내려받아 씁니다.
- 화면·양식·결과 엑셀의 이름은 가이드라인·혁신법 용어지만, 칸에 들어가는 판정 값(초과·근접·미달 등)·확인 표시·과제 상태 문구는 기준값 표와 맞추려고 1.0.0 그대로입니다(예: 'AI가 읽은 기준값(원문 확인 필요)', '관련 고시 항목 없음'). 간단한 결과(화면의 상세 보기 밖, 결과 엑셀 `초과·근접 조항`·`과제별 검토 결과` 시트)만 판정을 세 이름(고시 사양 초과·고시 사양 근접·고시 사양 미달 — 1.3.x까지는 셋째가 `사양 미달 또는 무관`)으로 바꿔 보입니다.
- '추가 검토 필요'의 세부 기술 일치는 AI 판단과 의미 검색이 둘 다 맞을 때만 남기므로 잘못 남는 것은 줄지만 놓칠 수 있습니다. 감춘 조항은 상세 보기·결과 엑셀 `고시 조항별 상세`에 남고 건수가 처리내역(숨김 시트)에 남습니다. 이중용도 관련 과제는 '추가 검토 필요'가 길어질 수 있습니다(숫자 기준 없는 이중용도 항목 180개).
