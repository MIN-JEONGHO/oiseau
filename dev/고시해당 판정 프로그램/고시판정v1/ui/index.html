    초과·근접 고시 조항

    최종목표 사양이 고시 기준 사양을 충족(초과)하거나 근접한 고시 조항. 넘거나 근접한 사양마다 한 줄

    미달 조항

    숫자로 비교했지만 고시 기준 사양에 못 미친 고시 조항

    추가 검토 필요

    숫자로 비교하지 못한 고시 조항 중 이중용도 관련이거나 세부 기술 일치(AI·검색)인 조항. 원문 확인 필요. 판정 아님

      검토 대상 고시

      예상 AI 호출 수 확인 중

      이번 실행 설정

      연구개발과제명과 과제요약정보 세 칸(또는 확인한 첨부 발췌)이 있을 때 검토 가능

      연구개발과제 일괄 검토

      입력 엑셀의 여러 연구개발과제를 한 번에 대조

      입력 파일

      저장하지 않음
      선택하지 않음

      검토 대상 고시

      입력 엑셀 선택 뒤 예상 호출 수 표시

      이번 실행 설정

      동시 처리 3건. 취소 시 끝난 행 보존, 시작하지 않은 행은 취소 상태. 이어하기 없음

      일괄 검토 결과

      건수를 누르면 그 결과의 과제만 보임. 다시 누르거나 '전체 보기'를 누르면 처음 화면

      중점 검토 과제

      종합 결과가 고시 사양 초과·근접인 과제와 그 과제의 초과·근접 조항. 넘거나 근접한 사양마다 한 줄

      판정하지 못한 과제

      그 밖의 과제

      초과·근접한 사양은 결과 엑셀 '초과·근접 조항' 시트, 모든 비교는 '고시 조항별 상세' 시트에서 확인

      상세 보기

      입력 엑셀을 읽어 처리 건수를 확인한 뒤 시작 가능

      고시 검색

      통제번호나 낱말로 고시 조항 찾기. 같은 말·위아래 분야·비슷한 뜻까지 PC 안에서만 검색(AI 미사용, 검색어 미저장)

      검색어 입력 뒤 검색(엔터 가능)

      고시 조항 상세

      검색 결과 없음

      검색 결과

      검색어나 관련어가 글자로 들어 있거나 글자가 비슷한 조항. 줄을 누르면 원문 전체와 고시 기준 사양 목록

      검토 대상 고시통제번호조항 제목 · 분야찾은 이유

      비슷한 뜻(참고)

      뜻이 비슷해 보이는 조항이며 맞지 않는 것이 섞일 수 있음

      검토 대상 고시통제번호조항 제목 · 분야찾은 이유

      관련어 사전과 의미 유사 검색은 참고용이며, 고시 해당 여부는 원문으로 확인해야 함.

      설정

      AI 제공자·모델·키. 실행 중에는 시작한 설정 고정

      AI 제공자와 모델

      API 키

      키 상태 확인 중

      키는 현재 Windows 계정의 자격 증명에 이 프로그램 전용 이름으로 저장. 화면에는 키 유무만 표시

      고시 기준본

      검토의 범위

      고시 기준 사양이 있는 고시 조항만 대조. '관련 고시 항목 없음'은 공식 비해당이 아님. 확인 표시가 있는 고시 조항은 원문 확인 필요

      이 결과는 고시 수치 기준과의 참고 대조이며 고시 해당 여부의 공식 판정이 아님.
