# 고시 검색 의미 벡터 모델 비교 (spec 4.5, plan T1)

- 작성일: 2026-11-06. 이 PC: Windows 11, Python 3.14.2.
- 도구: `tools/fetch_search_model.py`(후보 내려받기·지문 확인) → `tools/compare_search_models.py`(비교, 소켓 차단 상태) → `tools/pack_search_model.py`(고른 모델을 배포 형식으로 묶고 `MODEL_INFO.json` 작성).
- 고시 자료: `notice_catalogue.load_catalogue()`의 실제 검토 항목 507개. 조항 글을 줄 단위로 모아 최대 300자 조각(머리 줄 `통제번호 제목 분야` 붙임)으로 나눠 조각 4,612개. 조항 점수 = 가장 비슷한 조각의 코사인 유사도.
- **벡터만** 사용(관련어 사전·글자 검색 없음). 기대 조항 중 가장 높은 순위가 상위 10건(디스플레이 20건) 안이면 통과. 여섯 중 다섯 이상이면 합격.

## 고른 모델과 이유

**minishlab/potion-multilingual-128M (MIT), 정적 단어 벡터 256차원**을 골랐다. 배포 형식은 낱말을 줄이고 행별 int8로 바꾼 것이다. 실행 라이브러리는 numpy 2.5.1(BSD-3-Clause)과 tokenizers 0.23.3(Apache-2.0)이다.

1. 합격(5/6) 모델은 e5_small_int8과 potion 계열뿐이다. e5는 onnxruntime·numpy만으로도 약 107MiB가 들고 모델이 129MiB라 합계 약 240MiB로 한도를 넘는다. 모델 안 낱말 표를 줄이는 ONNX 수술을 해도 라이브러리 몫 때문에 한도 안에 들기 어렵다.
2. potion 원본(489MiB)은 int8만으로도 203MiB라 한도를 넘는다. 그래서 낱말을 줄였다. 한글·ASCII·한자·기호로만 된 낱말, 한 글자 낱말, 고시 원문 507개 항목을 토큰화해 나온 낱말 11,810개는 모두 남겼다. 이렇게 500,353개 가운데 241,882개를 남겨 60.9MiB가 되었다. 토크나이저는 원본 그대로이고, 남긴 낱말의 벡터는 원본과 같다(int8 반올림 오차만). 시험 질의 순위와 유사도는 줄이기 전 int8과 소수 넷째 자리까지 같다(위 표).
3. 크기 한도 안에서 통과 수가 가장 많다(5/6). 한도 안의 다른 변형(static_mrl·potion 128)은 4/6이다.
4. 질의 벡터 계산이 0.1ms 정도로 빠르고 onnxruntime이 필요 없어 실행 의존성이 작다.

떨어진 질의: `드론` → 9A012가 14위다(10건 밖, 유사도 0.3412). 1위는 9D105(무인항공기 소프트웨어)이고 9A012와 관련된 조항들이 위에 있다. 관련어 사전(드론 ↔ 무인항공기 ↔ UAV)이 검색 결과 묶음에서 이 질의를 맡는다.

## 최소 유사도 상수 제안

- **제안 값: 0.32.** 김치찌개 최고 0.3022보다 높고, 통과 질의 기대 조항의 최저 유사도 0.3376(디스플레이 advanced:item:009)보다 낮다. 떨어진 드론의 9A012(0.3412)도 이 값 위다.
- 0.32 이상 조항 수: DRAM 17, 디스플레이 13, 이차전지 16, 드론 22, 암호 9, 레이저 12, 배터리 21, 무인항공기 30, 반도체 95, **김치찌개 0**, 날씨 예보 0, **된장국 5**.
- 여유가 좁다(0.302 대 0.338). 무관한 말이라도 `된장국`은 0.3554까지 올라 0.32에서 5건이 걸린다. 비슷한 뜻 묶음은 '맞지 않는 것이 섞일 수 있음' 안내와 함께 보이는 참고 묶음이므로 받아들일 만하다고 보지만, T3에서 시험 질의로 다시 확인한다.

## 인터넷 접속 없음 확인

- `tools/compare_search_models.py`는 시작할 때 `socket.socket`·`socket.create_connection`을 막고 돈다. 위 결과는 모두 그 상태에서 나왔다(종료 코드 0).
- 따로 새 프로세스에서 확인했다. import 전에 `HF_HUB_OFFLINE=1`·`HF_HUB_DISABLE_TELEMETRY=1`을 두고 `socket.socket`·`create_connection`·`getaddrinfo`를 막았다. 그 상태로 `MODEL_INFO.json`의 파일 7개 SHA256 확인, 모델 로딩, 조항 4,612조각 벡터, 질의 일곱 개를 돌렸다. 결과는 통과 5/6, 김치찌개 0.32 이상 0건, 접속 시도 0회, huggingface_hub·onnxruntime 미import, 종료 코드 0이다.
- numpy·tokenizers에는 사용 통계 전송 기능이 없다. `Tokenizer.from_file`·`np.load`만 쓰고 `from_pretrained`는 쓰지 않는다. tokenizers를 import해도 huggingface_hub는 불러오지 않는다(확인). 실행 코드와 빌드에서 지킬 점은 `MODEL_INFO.json`의 `runtime.offline`에 적었다.
