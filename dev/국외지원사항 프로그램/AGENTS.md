# 국외지원사항 통계

연구자가 신고한 국외 지원·지급 사항(NRI 연구자 raw·과제 raw)으로 통계를 낸다. 결과는 엑셀 분석 리포트, KISTEP 표준보고양식 한글 보고서, 화면 대시보드다. 원래 엑셀 파일(v5)의 보조시트·통계 수식을 pandas로 다시 구현했고, 원본 수식의 오작동은 바로잡았다.

## 범위
- **현재 버전**: `국외지원 자동산출 프로그램v4.3/`(`국외지원사항_통계산출.py`의 `VERSION = 'v4.3'`).
- **보존만 하는 폴더**(수정·삭제 금지): `국외수혜 자동산출 프로그램/`(v1), `…v2`, `…v3`, `…v3.2`, `…v3.5(국가연구자번호 기준, 방어로직 추가)`, `…v3.7`, `…v3.8`, `…v3.9`, `…v4.0`, `…v4.2`.
  - 이 폴더들에 남은 결과 파일·zip도 사용자 확인 없이 옮기거나 지우지 않는다.

## 구조 (현재 버전)
- `국외지원사항_통계산출.py`: tkinter `App`(산출 판·대시보드 판)과 명령줄 `_cli()`. 파일 인수가 2개 이상이면 명령줄이다.
- `resources.py`: 자원 경로. `resource_path()`는 'exe·스크립트 옆 파일 → `sys._MEIPASS` 내장본' 순서로 찾는다. `export_resources()`가 [양식·테이블 내려받기]를 처리한다.
- `preprocessor.py`: 머리글 정규화(`norm_header`, `HEADER_ALIASES`), 병합 머리글 분리, 전처리 4단계, 제거 기준값(`DEFAULT_RULES`, 시트가 있으면 시트가 이긴다)
- `stat_engine.py`: 매핑 읽기, 산출기준일(`resolve_base_date`), 연구자 식별, 유형 판정(`TYPE_RULES`, `OTHER_KW`, `harden_money`), 관련성, 산·학·연, `compute_stats()` → 통계 dict `S`
- `report_builder.py`: 엑셀 9시트. `hwpx_writer.py`: 표준보고양식 채우기
- `dashboard.py`·`theme.py`: Canvas 대시보드와 디자인 토큰
- `make_icon.py`: 아이콘 생성(pillow, 빌드 산출물에 들어가지 않음)
- `매핑테이블.xlsx`·`표준보고양식.hwpx`: 내장 자원(`.spec` datas)
- `국외지원사항_통계산출.spec`: 단일 exe, matplotlib·PIL 등을 excludes로 뺌

## 경계
- 업무 규칙 값(기관 별칭, 민감국가, 소속 정규화, 전처리 제거값, 유형 키워드)은 `매핑테이블.xlsx` 몫이다. 규칙을 바꾸려고 코드 기본값만 고치지 않는다.
  - 코드 기본값(`DEFAULT_RULES`, `TYPE_RULES`)은 [전처리규칙]·[유형규칙] 시트가 없을 때를 위한 대비다.
  - [기관별칭]·[민감국가]·[소속정규화] 시트는 `load_mappings()`가 기본값 없이 읽으므로, 없으면 산출이 예외로 멈춘다.
  - 예외로 코드가 정하는 것: 기타 근거 표현 `OTHER_KW`, 금전 보정(`_MONEY_STRONG`·`_MONEY_COND`·`_MONEY_DEMOTE`·`MONEY_NEGATED`·`harden_money`), 산·학·연 키워드(`YEON_KW`·`HAK_KW`·`GITA_KW`), 관련성 판정 어구(`REL_*`).
- 대시보드와 리포트는 `compute_stats()`가 만든 `S`를 그리기만 한다. 다시 계산하지 않는다.
- 자원은 `resources.resource_path()`로만 찾는다. `__file__` 기준 상대 경로를 직접 쓰면 exe에서 깨진다.
- 차트 라이브러리(matplotlib 등)를 들이지 않는다. exe가 40MB에서 100MB를 넘어 '파일 하나 배포'가 어긋난다. 그림은 Canvas에 직접 그린다.
- 양식(`표준보고양식.hwpx`)과 매핑테이블은 사용자 업무 자산이다. 프로그램 수정 작업에서 내용을 바꾸지 않는다.

## 지켜야 할 것
- **산출기준일**
  - 연구자 raw 파일명 → 과제 raw 파일명 → 오늘(경고) 순서로 정한다.
  - 두 자리 연도는 구분자가 있어야 인정하고, 없는 날짜는 건너뛴다.
  - 발행 표기(`연구윤리자산보호센터`가 든 문단)만 오늘 날짜로 채운다.
- **전처리**
  - 비교는 `norm_value()` 정리 후 완전 일치로만 한다.
  - 출처국가 대한민국·가나·가봉·가이아나 행은 지운다(세 나라는 입력 실수로 확정된 값).
  - '보수/자문료 지원 없음' 신고는 지우지 않는다.
  - 의심값은 지우지 않고 검토 후보로만 남긴다.
  - 단계별 제거 건수와 값은 로그 dict에 남긴다.
- **연구자 식별**
  - `norm_researcher_id()`로 번호를 정리한다.
  - 번호가 없으면 `성명:` 키를 쓴다.
  - 한 번호에 여러 성명이 붙으면 그 번호만 `번호|성명` 키로 쪼갠다.
- **보고의무 종료**: 모든 건의 종료일이 기준일보다 앞서야 하고, 종료일 미상이 하나도 없어야 한다. 같은 날이면 아직 종료가 아니다.
- **유형 판정**
  - 사유·내용을 따로 판정해 합집합을 낸다.
  - 기타는 여섯 유형이 모두 빠졌을 때만 붙인다.
  - 기타가 되기 직전에 `looks_like_money()`로 금액을 다시 본다. 이미 다른 유형이 붙은 건은 건드리지 않는다.
  - 유형 중복건수 = 유형별 합 − 총건수 ≥ 0.
- **정부연구비**는 과제번호로 중복을 지운 뒤 더한다.
- **월별 표**: hwpx 월별 표의 합계가 날짜를 인식한 총 등록 건수와 다르면 경고를 남긴다. 양식에서 표를 못 찾으면 건너뛰고 경고한다. 한글 보고서가 실패해도 엑셀은 남긴다.
- **창 생성**: `Tk()`를 만들기 전에 `enable_dpi_awareness()`를 부른다. 픽셀 상수는 `theme.px()`를 거친다.

## 시험
- 자동 시험은 없다. 바꾼 뒤에는 합성 raw 두 파일로 명령줄을 실행한다.
  - 실행: `python 국외지원사항_통계산출.py 합성연구자_20260101.xlsx 합성과제_20260101.xlsx 결과.xlsx`
  - 합성 자료에 넣을 경우
    - 번호 미기재, 한 번호 여러 성명
    - 종료일 미상, 종료일 = 기준일
    - 출처국가 가나, 무효값, '보수/자문료 지원 없음'
    - 금액만 있는 내용(`1,500,000/월`), `공동연구` 단독
    - 병합 머리글과 한 칸 기간 두 형식
    - 파일명 날짜 없음
- 확인할 것
  - 처리 내역 경고(기준일·별칭 충돌·전처리)
  - [전처리 내역]·[유형 분류 내역]·[보고의무 종료 연구자] 시트
  - hwpx를 한글로 열었을 때 표 7개와 월별 표 열 구성
- 파일 종류를 바꿔 넣으면 멈추는지도 확인한다.
- 실제 raw를 시험 자료로 쓰지 않는다. 결과 파일은 저장소 밖에 만든다.
- 빌드: `python -m PyInstaller 국외지원사항_통계산출.spec` → `dist\국외지원사항_통계산출.exe`. 빈 폴더에서 exe만으로 엑셀·한글 보고서가 모두 나오는지 확인한다.
