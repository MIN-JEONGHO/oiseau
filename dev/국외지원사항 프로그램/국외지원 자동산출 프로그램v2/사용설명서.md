# 국외지원사항 자동 통계산출 프로그램

기존 엑셀 파일(v5)의 보조시트 + 통계분석 로직을 파이썬으로 재구현한 프로그램입니다.
raw 파일 2개만 지정하면 통계분석 리포트(xlsx)가 자동 생성되며,
**보조시트 행을 늘리거나 참조 범위(5000행)를 신경 쓸 필요가 전혀 없습니다.** 데이터가 몇 만 건이어도 그대로 처리됩니다.

## 구성 파일

| 파일 | 역할 |
|---|---|
| `국외지원사항_통계산출.py` | 메인 프로그램 (GUI + 명령행 겸용) |
| `stat_engine.py` | 통계 산출 엔진 (엑셀 수식 로직 재현) |
| `report_builder.py` | 엑셀 리포트 생성 (서식 포함) |
| `매핑테이블.xlsx` | **기관별칭(271건)·민감국가(21건)·소속정규화(48건)** — 기존 보조시트에서 그대로 추출 |
| `app_icon.ico` / `app_icon.png` | 프로그램 아이콘 (관인 인장 모티프) |

## 사용 방법 (GUI)

1. 프로그램 실행 → 창이 뜸
2. ① 연구자 raw 파일 선택 (연구자raw 시트가 들어있는 파일, 또는 연구자 데이터만 있는 단독 파일)
3. ② 과제 raw 파일 선택 — 두 시트가 한 파일에 있으면 **같은 파일을 두 번 선택**하면 됩니다 (①을 고르면 ②에 자동 입력)
4. [통계 산출 실행] 클릭 → `통계분석결과_날짜_시간.xlsx` 생성

명령행에서도 사용 가능합니다:
```
python 국외지원사항_통계산출.py 연구자raw.xlsx 과제raw.xlsx [출력파일.xlsx]
```

## 결과 리포트 구성 (4개 시트)

1. **통계분석** — 기본통계, 상위 국가 Top 20, 연도별/월별, 소속기관 Top 20, 연구자 Top 10, 과제 관련성, 지원유형별, 산·학·연·기타, 연구보안 우려 요약
2. **기관 Top30** — 별칭 통합 + 소재국가 + 연구자 소속 교차분석
3. **연구보안 세부** — DOE 위험·민감국가 수혜 내역 전체 리스트
4. **미매핑 연구자** — 과제 매핑이 진행되지 않은 연구자의 신고 내역 전체 (기존 보조시트2)

## 매핑 규칙 수정 (코딩 불필요)

새로운 기관 별칭이나 소속기관 정규화가 필요하면 `매핑테이블.xlsx`만 수정하세요.
- **기관별칭** 시트: 원본 표기 → 정규화 명칭 (예: `US NIH` → `NIH(미국 국립보건원)`)
- **민감국가** 시트: 국가명 → 위험국가/민감국가
- **소속정규화** 시트: 산학협력단 → 본교 등

행을 추가/삭제하고 저장만 하면 다음 실행부터 바로 반영됩니다.

## 실행프로그램(.exe) 만들기

파이썬이 설치된 윈도우 PC에서 한 번만 빌드하면, 이후에는 파이썬 없는 PC에서도 실행됩니다.

```bat
pip install pandas openpyxl pyinstaller
pyinstaller --onefile --windowed --icon app_icon.ico --name 국외지원사항통계산출 국외지원사항_통계산출.py
```

- 빌드가 끝나면 `dist\국외지원사항통계산출.exe`가 생성됩니다.
- **exe와 같은 폴더에 `매핑테이블.xlsx`, `app_icon.ico`, `app_icon.png`를 함께 두세요.** (프로그램이 자기 위치에서 자동으로 찾음. 아이콘 파일이 없어도 동작에는 지장 없음)
- 사내 보안 프로그램이 exe를 차단하면, 파이썬 설치 후 `.py`를 직접 실행하는 방식도 동일하게 동작합니다.

## 기존 엑셀과의 차이점 (개선 사항)

- 참조 범위 제한 없음: 5000행 하드코딩이 사라져 데이터 건수 무제한
- 연도/월별 통계가 고정값(2024~2028, 2026-01~12)이 아니라 **데이터에 있는 기간을 자동 인식**
- 지원·지급 유형 분류는 원본 대시보드(B67~B73)와 동일한 **다중 카운트 방식**: 한 건의 사유에 여러 유형이 포함되면 각 유형에 모두 집계되고, 합계는 총 건수, 아래에 중복건수가 표시됩니다
- 원본에서는 7개 유형 어느 키워드에도 해당하지 않는 사유(예: "해외 저널 심사 참여")가 아무 유형에도 집계되지 않아 유형 합계가 총 건수보다 작아질 수 있었습니다. 프로그램에서는 이런 미분류 건(빈 사유 포함)을 **'기타'로 집계**하여 모든 신고 건이 최소 한 유형에 속하고, 중복건수가 항상 0 이상이 되도록 했습니다
- 단, 원본의 '금전'(B70) 수식에는 다른 6개 유형과 달리 행 단위 판정(`>0`)이 누락되어 건수가 아닌 키워드 등장 횟수를 세는 버그가 있었습니다(금전 건수가 총 건수보다 커짐). 파이썬에서는 다른 유형과 동일하게 "금전 키워드가 하나라도 포함된 건수"로 집계하도록 바로잡았습니다
- 연구보안 세부 리스트와 미매핑 연구자 리스트가 잘리지 않고 전체 출력됩니다
