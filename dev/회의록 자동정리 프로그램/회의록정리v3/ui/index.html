설정

전사와 요약을 나눠 처리합니다. 음성을 글자로 바꾸는 일은 OpenAI Whisper가, 그 글자를 읽어 발언자 매칭과 기관별 요약을 하는 일은 OpenAI GPT가 맡습니다. 둘 다 프로그램에 내장된 API 키 하나로 동작합니다.

① API 키 · 사용 모델 전사 · 요약 공용

키와 모델은 모두 프로그램에 고정되어 있습니다. 바꿔야 하면 embedded_key.py / config.py 를 고치고 다시 빌드하세요.

② 문서 기본값

제목 아래 괄호에 들어갑니다. 예: (’26. 9. 4., KISTEP 연구윤리자산보호센터)

1녹음파일 전사

회의 녹음파일을 올리면 음성인식 엔진이 글자로 바꿉니다. 이 단계에서만 녹음파일이 사용됩니다.

녹음파일

녹음파일을 여기로 끌어놓거나 눌러서 선택
mp3 · m4a · wav · flac · ogg · opus · aac · wma · mp4 · webm
선택됨

전사 실행

1시간 녹음 기준 약 1~3분 걸립니다.

전사 결과

세션을 저장해두면 나중에 전사를 다시 하지 않고 이어서 작업할 수 있습니다.

2참석자 · 발언자

참석자를 입력하면 AI가 전사문을 읽고 누가 어떤 발언을 했는지 배정합니다. 결과는 아래에서 직접 고칠 수 있습니다.

참석자 명단 기관은 회의록의 "기관별 요약" 항목이 됩니다

이름기관직위
같은 기관의 여러 사람은 그대로 여러 줄로 넣으세요. 회의록에서는 기관 단위로 묶입니다.

발언자 매칭

전사문 확인 · 수정

3기관별 요약

회의 정보를 확인하고 요약을 생성합니다. 생성된 내용은 모두 문서로 나가기 전에 고칠 수 있습니다.

회의 정보

문서 제목은 "제목 + 회의록" 으로 들어갑니다. 비워두면 AI가 지어냅니다.
비워두면 위 날짜만 들어갑니다.

요약 생성
