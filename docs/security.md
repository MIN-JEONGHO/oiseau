# 보안 원칙

## 보호 대상

| 대상 | 있는 곳 | 노출되면 |
|---|---|---|
| OpenAI API 키 | 회의록 `embedded_key.py`(v1~v3.1), 회의록 exe 안 | 유료 호출 남용 |
| Anthropic API 키 | 리포트 v3·v4 `rmonitor/_secrets.py`, 리포트 exe 안, 리포트 v1·v2 `config.json` | 유료 호출 남용 |
| 메일(SMTP) 비밀번호 | 리포트 v1·v2 `config.json` | 메일 계정 도용 |
| 국외지원 원자료·결과물 | 연구자 성명·국가연구자번호·소속·지원 내용 | 개인정보 유출 |
| 제재통계 원자료·결과물 | 제재 대상(기관·인물)·과제·금액 | 제재 정보·개인정보 유출 |
| 회의 녹음·전사문·요약·세션 | 회의 내용·참석자 | 비공개 업무 내용 유출 |
| 공공데이터 검토 대상 파일, 실호출 인증키 | 등록 전 데이터(개인정보가 섞일 수 있음), 기관의 serviceKey | 개인정보·인증 정보 유출 |

보안등급분류 시뮬레이터의 키·자료·전송 정책은 그 폴더가 자체로 정한다.

## 누가 무엇을 할 수 있나

로그인 기능은 없다. exe를 실행한 Windows 사용자가 곧 사용자다.

| 주체 | 할 수 있는 것 | 하지 않는 것·막힌 것 |
|---|---|---|
| 그 PC의 사용자 | 모든 기능 | — |
| exe를 받은 센터·부서 동료 | 모든 기능. 내장 키로 유료 API를 호출할 수 있고, 마음먹으면 exe에서 키 문자열을 꺼낼 수 있다 | 센터·부서 밖으로 exe를 다시 나누지 않는다 |
| 같은 PC의 다른 프로그램·웹페이지 | 제재통계·리포트·회의록의 화면 서버(127.0.0.1 임의 포트)에 요청을 보낼 수 있다. 요청에 토큰·출처 확인이 없어서 파일 열기, 설정 변경, 유료 AI 호출을 일으킬 수 있다 | 사내 PC를 한 사람이 쓴다는 전제로 이 위험을 받아들인다(2026-10-23 사용자 결정) |
| 다른 PC | 접근할 수 없다. 서버가 127.0.0.1에만 묶여 있다 | 바인딩을 0.0.0.0이나 외부 인터페이스로 넓히지 않는다. 넓히면 위의 전제가 깨진다 |

공공데이터 도구는 HTTP 서버 없이 창 안에서 파이썬 객체를 직접 호출하므로, 다른 프로그램이 끼어들 통로가 없다.

## API 키 관리

| | 회의록 | 리포트 v3·v4 |
|---|---|---|
| 보관 | `embedded_key.py`의 `OPENAI_API_KEY`. 빌드할 때 exe에 묶인다 | `rmonitor/_secrets.py`의 `ANTHROPIC_API_KEY`. 빌드할 때 exe에 묶인다 |
| 사용 순서 | 내장 키가 있으면 내장 키. 없을 때만 환경변수 `OPENAI_API_KEY` | 환경변수 `RM_LLM_API_KEY`가 있으면 그것. 없으면 내장 키 |
| 화면·설정 파일 | 키를 화면으로 보내지 않고 설정 파일에도 쓰지 않는다. 설정 파일 `%APPDATA%\KISTEP회의록정리\config.json`에는 작성 부서 같은 문서 기본값만 저장한다 | 키 입력 화면이 없고, `config.json`에 키 항목이 없다 |
| 교체 | 파일을 고쳐 다시 빌드하고 다시 배포한다 | 환경변수로 바로 바꾸거나, 파일을 고쳐 다시 빌드한다 |
| 키가 없을 때 | 설정 탭에 빨간 안내, 전사·요약 단계에서도 같은 안내 | 실행할 때 키 설정 안내와 함께 실패 |

- 배포 범위는 같은 센터·부서 동료까지다. 더 넓게 나눠야 하면 키를 exe에 넣는 방식부터 다시 정한다.
- 키가 노출되었거나 그렇게 의심되면 다음 순서로 처리한다. 제공자 콘솔에서 그 키를 폐기하고, 새 키로 교체하고, 다시 빌드해 배포하고, 이전 exe를 회수한다.
- 리포트 v1·v2의 `config.json`에는 LLM 키와 SMTP 비밀번호가 평문으로 들어 있다. 이전 버전이라 파일은 고치지 않고, 커밋 제외로만 막는다.
- v1·v2의 `config.json`을 v3·v4 폴더나 exe 옆으로 옮기지 않는다. v3·v4의 설정 읽기는 모르는 항목도 그대로 합쳐 두고, 설정 화면이 설정 전체를 화면으로 보낸 뒤 다시 저장한다. 그래서 옮기면 예전 키와 비밀번호가 화면에 드러나고 계속 저장된다.

## 외부 API 인증과 실패 처리

- **리포트**
  - 키가 없으면 실행을 멈추고 설정 방법을 안내한다.
  - 4xx 오류는 다시 시도해도 결과가 같으므로 바로 실패시킨다. 429·408·5xx만 다시 시도한다.
  - `thinking` 매개변수가 거부되면 빼고 한 번 더 보낸다. 다른 매개변수가 거부되면 다시 보내지 않고 실패한다.
  - 응답이 길이 제한이나 안전상 거부로 끝나면 그 원인을 표시한다.
- **회의록**
  - 인증·한도·접근 오류(모델이 없으면 HTTP 404), 거부, 길이 초과, 빈 응답, JSON 오류는 안내 메시지와 함께 실패한다.
  - 다른 모델로 자동 대체하지 않는다.
  - 설정 탭의 '요약 모델 연결 테스트'는 키·모델 이름·구조화 출력을 실제 호출 한 번으로 확인한다. 소액이 과금된다.
- **공공데이터 실호출**: 연결 실패, 시간 초과, HTTP 오류도 결과에 담아 판정에 쓴다. 검토 전체를 멈추지 않는다.

## 외부 전송

- **회의록 → OpenAI**: 녹음 파일(전사 단계), 전사문·참석자 명단·회의 정보(매칭·요약 단계)가 나간다. 민감한 회의는 이 프로그램으로 처리하지 않으며, 민감한지는 사용하는 사람이 판단한다. 기관 차원의 명시적 허용 규정은 확인되지 않았다.
- **리포트 → Anthropic**: 기간·카테고리를 채운 수집 지시문만 나간다. 업무 자료는 넣지 않는다. 응답 원문은 `output/*_raw.txt`에 남는다.
- **공공데이터 → 등록 API 서버**: 사용자가 실호출을 켰을 때만 인증키를 붙인 GET을 보낸다. 사내망에서 외부 호출이 막혀 있으면 끄고 쓴다.
- **국외지원·제재통계**: 밖으로 보내는 것이 없다.
- **화면**: 외부 CDN·웹폰트·원격 자원을 부르지 않는다.

## 업무 자료 보관

- 원자료와 결과물(연구자·제재 대상·회의 내용이 든 파일)은 프로그램 폴더 밖에 둔다. 저장소 안의 프로그램 폴더에는 두지 않는다.
- 프로그램별 기본 저장 위치
  - 국외지원: 프로그램(exe·스크립트) 폴더다. 원칙과 어긋나므로 실행 전에 [저장폴더]를 바깥 폴더로 바꾼다.
  - 제재통계: 문서 폴더의 `제재통계`.
  - 공공데이터·회의록: 저장할 때 고른 폴더.
  - 리포트: exe 옆 `output`·`logs`·`history`·`data`(공개 동향 자료).
- 시험에는 합성 자료와 모의 응답만 쓴다. 실제 원자료, 실제 회의 녹음, `embedded_key.py`, `_secrets.py`를 시험 자료로 읽지 않는다.

## 남겨야 하는 기록

데이터를 빼거나 바꾸는 처리는 조용히 하지 않고 근거를 남긴다. 아래 기록을 없애거나 줄이는 변경은 하지 않는다.

- **국외지원**
  - 전처리 단계별 제거 건수·제거 값·검토 후보([전처리 내역] 시트)와 열 인식 방식
  - 산출기준일과 그 날짜를 가져온 파일명(오늘 날짜로 대체했으면 경고)
  - 매핑테이블 별칭 충돌, 번호 미기재 건수, 한 번호에 여러 성명이 붙은 경우
  - 건별 유형 판정 근거([유형 분류 내역] 시트)
  - 월별 표 합계와 총 등록 건수의 차이
- **제재통계**
  - 실제 적용된 부처명 치환과 건수, 값별 기관유형 편입 건수
  - 금액 변환에 실패한 건수와 값, 연구수행주체를 어느 열에서 가져왔는지
  - 범위 밖·분류 밖으로 빠진 건수, 참조데이터에 없는 부처
  - 검산 결과(처분연도 기준은 엑셀 `검산` 시트, 연구수행 기준은 화면의 검산 표시)
- **리포트**: 검증에서 뺀 이슈와 사유(결과 JSON의 제외 목록, 로그), AI 응답 원문, 실행 이력(`history/history.jsonl`)
- **공공데이터**: 실호출한 URL(키는 가림)·상태코드·응답시간([API실호출] 시트), 프로그램이 읽어 들인 명세 전체([API명세]·[API에러코드] 시트)

## 저장소

- 커밋하지 않는 것
  - 키·비밀번호가 든 파일: `embedded_key.py`, `rmonitor/_secrets.py`, 리포트 `config.json`, `.env`, 키 형태 문자열이 든 보안등급분류 시뮬레이터의 `security_grade_classifier_v10_claude.py`·`security_grade_classifier_v12_claude.py`
  - build·dist·exe·배포용 zip. exe 안에 내장 키가 들어 있다
  - 실행 산출물과 업무 자료
  - 자체 git 저장소를 가진 하위 폴더
- 위 범주는 저장소 맨 위 `.gitignore`에 등록되어 있다. 다만 `.gitignore`는 새 파일 이름까지 막아 주지 못하므로, 스테이징은 경로를 하나씩 지정한다. 폴더째 추가하거나 전체를 추가하지 않는다.
