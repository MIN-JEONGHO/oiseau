# 작업 규칙

## 버전 폴더

- 수정은 아래 현재 버전 폴더에서만 한다(`dev/` 기준).

  | 프로그램 | 현재 버전 폴더 |
  |---|---|
  | 공공데이터 등록 사전검토 | `공공데이터 DB검증 프로그램/공공데이터 DB검증v4/` |
  | 국외지원사항 통계 | `국외지원사항 프로그램/국외지원 자동산출 프로그램v4.3/` |
  | 제재통계 | `제재통계 프로그램/통계v6/` |
  | 연구보안·연구윤리 동향 리포트 | `연구보안연구윤리 월간메일링/v4/` |
  | 회의록 자동정리 | `회의록 자동정리 프로그램/회의록정리v3.1/` |

- 이 밖의 버전 폴더와 파일은 수정·삭제·이동하지 않는다. 제재통계 맨 위의 `sanction_stats.py`, `복합통계v1·v2`, 공공데이터의 `v4` 백업 폴더도 여기에 포함된다. 현재 버전 폴더 밖의 파일이 변경 목록에 나타나면 위반이다.
- 새 버전 폴더를 만들지, 현재 폴더를 고칠지는 사용자가 정한다. 새 버전을 만들 때는 다음을 따른다.
  - 현재 폴더를 통째로 복사해 다음 번호를 붙인다(`…v4.4`, `통계v7`).
  - 복사본에서 build·dist·`__pycache__`·실행 산출물·실제 자료를 지운다.
  - 이전 폴더는 그대로 둔다.
- 버전 폴더끼리, 프로그램끼리 import하거나 파일을 참조하지 않는다. 각 버전 폴더는 그 안의 파일만으로 실행·빌드되어야 한다.
- 보안등급분류 시뮬레이터 안의 작업은 그 폴더의 지침을 따른다.

## 커밋

- 커밋과 푸시는 사용자가 요청할 때만 한다.
- 스테이징은 경로를 하나씩 지정한다. `git add -A`, `git add .`, `git add dev/`처럼 폴더째 추가하지 않는다.
- 커밋에 넣지 않는 것
  - 키·비밀번호가 든 파일
  - build·dist·exe·배포용 zip
  - 실행 산출물
  - 실제 원자료·결과물·회의 자료·감사 기록
  - AI 작업 도구가 만드는 작업·상태 폴더(`.bkit/` 등, `.gitignore`에 등록됨)
- 커밋 전 `git diff --cached --name-only`에 `embedded_key.py`·`_secrets.py`·`config.json`·`_claude.py`·`.exe`·`.zip`·`dist/`·`build/`가 하나라도 보이면 위반이다.
- 자체 git 저장소가 있는 폴더(`회의록정리v3.1` 등)는 그 저장소에서만 커밋한다. 상위 저장소에서 스테이징하지 않는다.

## 검증 — 변경 후 통과해야 하는 것

| 프로그램 | 자동 검증 (버전 폴더에서 실행) | 추가 확인 |
|---|---|---|
| 공공데이터 | `python tests/test_rules.py`, `python tests/test_api_rules.py` 둘 다 종료 코드 0 | 판정 기준이나 자동수정을 바꾸면 그 경계값 시험을 추가한다 |
| 회의록 | `python -m unittest discover -s tests -p test_summary_model.py`, `python selftest.py` 둘 다 종료 코드 0 | 배포 전 요약 모델 연결 테스트와 합성 회의 전 과정 확인(수동) |
| 국외지원 | 없음 | 합성 raw로 명령줄을 실행해 처리 내역 경고, [전처리 내역]·[유형 분류 내역] 시트를 확인하고, hwpx를 한글로 열어 표를 확인한다 |
| 제재통계 | 없음 | 합성 rawdata로 **화면(`python app.py`)에서** 두 통계를 실행해, 두 탭의 검산과 처분연도 기준 엑셀 `검산` 시트가 모두 ✓인지 확인한다. 연구수행 기준 검산은 화면에서만 계산되므로 명령줄 실행으로는 확인할 수 없다 |
| 리포트 | 없음 | `--data data/sample_*.json`으로 월간·주간 렌더링, 누적 엑셀, 이력 기록을 확인한다. 실제 누적 파일이 아닌 복사본 폴더에서 돌린다 |

- 실제 유료 API, 외부 서버, 실제 업무 자료는 자동 검증에 쓰지 않는다. 사용자가 그 작업에서 명시적으로 요청한 경우에만 쓰고, 그 결과는 자동 검증과 구분해 보고한다.
- 빌드를 바꿨으면 빌드 종료 코드 0과 exe 단독 실행(빈 폴더에 exe만 둔 상태)을 확인한다. 확인하지 못한 항목은 '미확인'으로 보고하고, 통과로 적지 않는다.

## 구조

- 판정·집계 로직은 엔진·파이프라인 모듈에만 둔다. 화면(HTML·JS·tkinter)과 명령줄은 같은 엔진을 부르고 결과를 표시만 한다. 화면 코드에 집계·판정 계산이 생기면 위반이다.
- 제재통계의 `monthly_pipeline.py`는 `sanction_pipeline.py`의 헤더 탐지·연도 추출·부처명 치환을 가져다 쓴다. 반대 방향 import나 같은 기능의 복제를 만들지 않는다. 그러면 두 통계가 같은 raw를 다르게 읽게 된다.
- 화면 서버는 127.0.0.1에만 바인딩한다.
- 화면은 외부 CDN·웹폰트·원격 자원·브라우저 저장소를 쓰지 않는다. 화면은 인터넷 연결 없이 뜨고 동작해야 한다. 외부 연결은 AI 호출(리포트·회의록)과 공공데이터 실호출뿐이다.
- exe 실행에 필요한 자원(양식·매핑표·화면 파일·프롬프트)은 `.spec`의 datas나 소스 안의 문자열로 exe에 넣는다. 실행 중에는 그 프로그램의 자원 경로 함수로만 경로를 얻는다. 스크립트 기준 상대 경로를 직접 쓰면 exe에서 깨진다.

## 규칙을 바꾸는 자리

같은 규칙을 두 곳에 두지 않는다.

| 프로그램 | 바꾸는 자리 |
|---|---|
| 공공데이터 | 조항 판정은 `checker/rules_csv.py`·`rules_file.py`·`rules_meta.py`(파일데이터)와 `checker/rules_api.py`(OPEN API). 자동수정 정책은 `checker/fixer.py`의 `FIXABLE`·`NOT_FIXABLE_REASON`, `checker/api_fixer.py`의 `API_FIXABLE`·`API_NOT_FIXABLE_REASON` |
| 국외지원 | 기관 별칭·민감국가·소속 정규화·전처리 제거값·유형 키워드는 `매핑테이블.xlsx`. 코드 기본값(`DEFAULT_RULES`, `TYPE_RULES`)은 [전처리규칙]·[유형규칙] 시트가 없을 때를 위한 대비이고, [기관별칭]·[민감국가]·[소속정규화] 시트는 반드시 있어야 한다. 코드에서 바꾸는 것: 기타 근거 표현(`OTHER_KW`), 금전 보정(`harden_money`, `MONEY_NEGATED` 등), 산·학·연 키워드(`YEON_KW`·`HAK_KW`·`GITA_KW`), 관련성 판정 어구(`REL_*`) |
| 제재통계 | 제재사유 9분류(`REASON_GROUPS`)·기관유형(`ORG_LABELS`·`ORG_ALIAS`)·부처 목록(`MINISTRY_LABELS`)은 `monthly_pipeline.py`, 부처 개편 매핑(`MINISTRY_RENAME_CONFIRMED`·`MINISTRY_RENAME_INFERRED`)은 `sanction_pipeline.py`. 열 별칭 사전은 두 파일에 따로 있으므로(`REQUIRED_COLUMNS`·`OPTIONAL_COLUMNS`와 `M_REQUIRED`·`M_OPTIONAL`) 함께 고친다 |
| 리포트 | 수집 범위·작성 규칙은 `prompts/*.txt`, 국가·카테고리·국가별 상한·제목 문구는 `rmonitor/profiles.py`, 모델·요청 정책은 `rmonitor/llm.py` |
| 회의록 | 모델은 `config.py`의 `STT_MODEL`·`SUMMARY_MODEL`. 화면에서 모델을 바꾸는 기능을 만들지 않는다 |

- 산출 숫자를 바꾸는 기본값은 사용자 확인 없이 바꾸지 않는다. 예를 들어 제재통계의 과제 묶기 `과제명`, 과제유형 `전체`, 과제수행연도 하한 2017이 그렇다. 바꾸면 이미 보고한 산출물과 숫자가 달라진다. 사용자 확인 없이 이런 기본값이 바뀐 변경은 위반이다.

## 의존성

- 의존성 목록은 버전 폴더에 `requirements.txt`가 있으면 그것이고, 없으면(국외지원·제재통계) README·사용설명서의 설치 명령이다. 패키지를 더하거나 빼면 그 목록, `.spec`의 hiddenimports·excludes, `build_exe.bat`의 설치 줄을 함께 고친다.
- 표준 라이브러리 `urllib`로 HTTP를 하는 곳(공공데이터 실호출, 회의록)에는 SDK나 `requests`를 들이지 않는다. 리포트만 `requests`를 쓴다.
- 그래프는 직접 그린다(국외지원은 Canvas, 제재통계는 SVG). matplotlib 같은 차트 라이브러리를 import하면 위반이다. 국외지원 exe가 40MB에서 100MB를 넘게 된다.

## 인코딩과 표기

- 소스·문서·설정은 UTF-8이다.
- 한글 파일명·폴더명·시트명·양식 문구를 바꾸지 않는다. 사람과 다른 문서가 그 이름으로 찾는다.
- 고치는 범위 밖의 재서식화(줄바꿈·따옴표·정렬 정리)를 하지 않는다. 버전 폴더끼리 비교할 때 잡음이 된다.
