# 0007. 공공데이터: OPEN API 기술문서는 고치지 않고 대조표만 만든다

- 상태: 확정(사용자 확인 2026-10-23)
- 적용: 공공데이터 등록 사전검토 OPEN API 검토(프로그램 3.0.0부터)

## 맥락
OPEN API 검토에서 고칠 대상은 포털 등록 화면에 넣는 값이다. 기술문서(Swagger·오퍼레이션 명세표)와 등록 내용이 어긋나면 12-나로 반려된다.

## 결정
- 자동수정은 등록 정보만 고친다. 결과는 '전 → 후' 대조표와 수정 등록정보 JSON이다.
- 기술문서 파일은 고치지 않는다. 문서에서 고쳐야 할 값은 따로 목록으로 알린다.

## 고려한 대안
- **기술문서도 자동으로 고치기**: 기관이 배포한 문서를 도구가 말없이 바꾸면 원본과 어긋나 12-나 반려를 새로 만든다.

## 결과
- 기술문서 쪽 결함은 담당자가 직접 고쳐야 한다.
- 수정 후 재검토는 고친 등록 정보와 원래 명세로 한다.
- 파일데이터 자동수정(데이터 파일의 수정 사본 저장)과 결과물의 모양이 다르다.
