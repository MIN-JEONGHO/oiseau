# 0005. 리포트: AI는 사실만 모으고, HTML은 프로그램이 조립한다

- 상태: 확정(사용자 확인 2026-10-23)
- 적용: 연구보안·연구윤리 동향 리포트(v1부터)

## 맥락
예전에는 프롬프트를 붙여넣고 LLM이 HTML 리포트 템플릿을 직접 편집했다. 그러자 태그가 깨지고 자리표시자가 남았으며, 리포트 내용과 엑셀 기록이 서로 어긋났다.

## 결정
- LLM은 웹 검색으로 이슈를 모아 정해진 JSON 형식(이슈 필드 목록)으로만 돌려준다.
- 프로그램이 그 JSON을 검증한다(대상국, URL 형식, 중복 URL, 국가별 상한).
- 같은 데이터로 HTML 리포트와 누적 엑셀을 만든다.

## 고려한 대안
- **LLM이 HTML을 직접 만들거나 고치기**: 위 문제(태그 깨짐, 자리표시자 잔존, 엑셀과 불일치) 때문에 기각했다.

## 결과
- 리포트 디자인은 렌더러 코드에서만 바꾼다. 프롬프트로는 바꿀 수 없다.
- 이슈에 새 필드를 넣으려면 프롬프트, 검증, 렌더러, 엑셀 열을 함께 고쳐야 한다.
- LLM 응답이 JSON이 아니면 그 리포트는 실패한다. 원인은 `output/*_raw.txt`로 확인한다.
- 검증을 통과한 이슈가 0건이면 '특이사항 없음' 리포트가 나온다.
