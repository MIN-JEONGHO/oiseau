# 0004. 로컬 화면 서버에 잠금을 두지 않는다

- 상태: 확정(사용자 결정 2026-10-23)
- 적용: 제재통계, 연구보안·연구윤리 동향 리포트, 회의록 자동정리

## 맥락
세 도구는 127.0.0.1의 임의 포트에 HTTP 서버를 띄우고 웹 화면이 `/api/*`를 호출한다. 요청에 토큰이나 출처(Origin) 확인이 없다. 그래서 같은 PC의 다른 프로그램이나 브라우저의 웹페이지가 포트를 찾아내면 다음 일을 일으킬 수 있다.
- 파일 열기(`/api/open` → `os.startfile`)
- 설정과 경로 바꾸기
- 내장 키로 유료 AI 호출(리포트 수집, 회의록 전사·요약)

## 결정
사내 PC를 한 사람이 쓴다는 전제로 지금 방식을 유지한다.

## 고려한 대안
- **요청마다 세션 토큰과 출처 확인을 추가**: 사내 PC 전제에서는 필요하지 않다고 보고 넣지 않았다.

## 결과
- 서버는 127.0.0.1에만 바인딩한다. 0.0.0.0이나 외부 인터페이스로 넓히면 이 결정의 전제가 깨진다.
- 같은 PC에서 악성 웹페이지를 열었을 때 파일 열기나 유료 호출이 일어날 수 있는 위험을 감수한다.
- 개인 PC·공용 PC에서 쓰거나 배포 범위가 넓어지는 등 전제가 바뀌면 다시 정한다.
- 공공데이터 도구는 HTTP 서버가 없어 이 결정과 관계없다.
