# 0006. 리포트: 메일 발송 기능을 없앤다

- 상태: 확정(사용자 확인 2026-10-23)
- 적용: 연구보안·연구윤리 동향 리포트(v3부터)

## 맥락
v1·v2는 SMTP로 리포트를 메일 발송했고, 수신자·SMTP 계정을 `config.json`에 두었다. 사내 발송 권한 문제로 이 방식을 계속 쓸 수 없게 되었다.

## 결정
- v3부터 SMTP 연동을 모두 지웠다(`mailer.py`, 메일 설정, `--test-mail`, 수신자 항목).
- 리포트는 항상 HTML 파일로 저장한다. 사람이 [다른 이름으로 저장]으로 내보내 메일 프로그램으로 전달한다.

## 고려한 대안
- **SMTP 발송 유지**: 사내 발송 권한 문제로 쓸 수 없다.

## 결과
- 자동 발송은 없다. 예약 실행도 리포트 파일 생성까지만 한다. 배치 파일 이름(`실행_자동발송.bat`)은 예전 그대로다.
- `config.json` 형식이 v2와 달라 v2 설정을 그대로 쓸 수 없다.
- 메일 발송을 다시 넣으려면 이 결정부터 다시 해야 한다.
