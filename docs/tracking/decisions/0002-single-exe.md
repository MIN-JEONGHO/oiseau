# 0002. exe 하나로 배포하고, 고쳐 쓰는 파일은 exe 옆에 둔다

- 상태: 확정(사용자 확인 2026-10-23)
- 적용: 모든 업무 도구. 옆 파일 우선 규칙은 국외지원, 화면에서 파일을 바꿔 넣는 방식은 제재통계

## 맥락
동료 PC에는 Python이 없다. 국외지원은 v4.1까지 exe와 매핑테이블·표준보고양식 등 파일 4개를 함께 옮겨야 했고, 하나라도 빠지면 한글 보고서가 만들어지지 않았다. 매핑테이블과 양식은 담당자가 고쳐 쓰는 파일이다.

## 결정
- 각 도구를 PyInstaller `--onefile` exe 하나로 만든다. 양식·매핑표·화면 파일·프롬프트는 exe 안에 넣는다.
- 국외지원은 'exe(또는 스크립트) 옆 파일 → exe 내장본' 순서로 자원을 찾는다. [양식·테이블 내려받기]로 내장본을 꺼내 고쳐 쓰게 한다. 화면 경로 앞에 `[내장]`·`[수정본]`·`[지정]`을 표시한다.
- 제재통계는 내장 양식·참조데이터를 쓰되, 화면에서 다른 파일을 넣으면 그 파일을 대신 쓴다.

## 고려한 대안
- **exe와 자원 파일을 묶어서 배포**: 파일 하나만 빠져도 보고서가 실패한다.
- **Python을 설치하고 `.py`를 실행**: 동료 PC에 Python이 없다. 다만 사내 보안 프로그램이 exe를 막을 때는 이 방식으로 대신한다.

## 결과
- 내장 기본값은 빌드할 때의 소스 폴더 파일이다. 규칙이나 양식을 바꾸면 다시 빌드하거나 옆 파일로 덮어써야 받는 사람에게 반영된다.
- exe 크기를 의식해야 한다. exe를 크게 불리는 라이브러리는 들이지 않는다.
- pywebview 화면을 쓰는 도구는 받는 PC에 WebView2 런타임이 있어야 한다. 없으면 exe 창이 구형 IE 엔진으로 떠서 화면이 동작하지 않는다.
- 키를 exe에 내장하는 방식도 이 배포 방식을 전제로 한다.
- 국외지원의 내려받기는 같은 이름의 파일이 있으면 덮어쓸지 먼저 묻는다('아니오'면 없는 파일만 내려받는다). 손으로 채운 별칭·규칙이 조용히 사라지는 일을 막으려는 것이다. 제재통계의 내장 파일 내려받기는 묻지 않고 덮어쓴다.
