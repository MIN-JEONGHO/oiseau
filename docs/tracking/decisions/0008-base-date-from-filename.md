# 0008. 국외지원: 산출기준일은 raw 파일명의 날짜다

- 상태: 확정(사용자 확인 2026-10-23)
- 적용: 국외지원사항 통계

## 맥락
통계의 기준 시점은 raw를 내려받은 날이다. 실행한 날을 기준으로 하면, 같은 raw를 며칠 뒤에 다시 돌렸을 때 보고의무 종료 판정, 보고서 날짜, 월별 표 열이 달라진다.

## 결정
- 연구자 raw 파일명에서 연·월·일을 찾고, 없으면 과제 raw 파일명에서 찾는다. 둘 다 없으면 오늘 날짜를 쓰고 경고한다.
- 두 자리 연도는 구분자가 있을 때만 인정하고, 없는 날짜는 건너뛴다.
- 표제 아래 발행 표기만 문서를 만든 날짜를 쓴다.

## 고려한 대안
- **실행일 기준**: 같은 raw로 같은 보고서를 다시 만들 수 없다.

## 결과
- raw 파일을 저장할 때 파일명에 날짜를 넣어야 한다. 파일명을 바꾸면 결과가 바뀐다.
- 판 번호(`v4.2`)가 날짜로 읽히지 않도록, 두 자리 연도는 구분자가 있어야만 인정한다.
- 날짜를 찾지 못한 실행은 처리 내역의 경고로만 드러난다. 경고를 놓치면 그날 기준으로 집계된다.
