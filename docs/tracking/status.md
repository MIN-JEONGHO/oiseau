## 남은 일 (먼저 할 것부터)

1. **회의록 v3.1 배포 전 실제 확인**: 새 exe에서 요약 모델 연결 테스트를 하고, 합성 회의 자료로 매칭 → 요약 → 수정 → 세션 저장·복원 → hwpx까지 확인한다. 400구간을 넘는 자료도 확인하고, 화면 표시와 한글 열람도 본다. 문제가 있으면 배포를 미룬다.
2. **제재통계 화면 육안 검수 — 남은 부분**: 2026-10-23에 소스의 화면 서버를 headless Edge(WebView2와 같은 Chromium 엔진)로 띄워 검수했다. 합성 rawdata를 쓰고, 1264×861·944×621·150% 배율에서 두 탭, 검산, 통계판, 그림 다섯 종류, 표, 각주, 툴팁, PNG 저장을 캡처해 확인했다. 배치가 깨진 곳은 없었다. 처분연도 기준의 빠진 건수(참여제한 −14, 환수금 −3, 제재부가금 −4)도 원자료에서 직접 센 값과 맞았다. 문제 세 가지는 2026-10-24에 `ui/index.html`에서 고치고, 같은 방법으로 다시 확인했다(화면 스크립트 오류 0건).
   - 작은 그림 묶음(추이)이 12칸을 넘는 부처·분류를 각주 없이 뺐다. 이제는 12개까지 그리고 "상위 12개만 (그 외 N개 생략)"을 적는다.
   - 처분연도 구성비의 5·6번째 범주가 같은 색이었다. 이제는 이름 붙은 범주를 5개까지만 두고 나머지는 '그 외'로 접는다.
   - 연구수행 기준 저장 안내가 '검산 시트 포함'이었으나 실제 엑셀에 `검산` 시트가 없었다. 이제는 '연도전개 시트 포함 · 검산은 화면에서 확인'으로 나온다.
   
   남은 것은 세 가지다. ① exe를 다시 빌드해 배포할지 정한다(지금 `dist`의 exe에는 이 수정이 없다). ② 빌드한 exe(pywebview 창)로 같은 확인을 한다. ③ 사람이 직접 화면을 본다.
3. **제재통계 참조데이터 2024년 이후 값 채우기**: 내장 `reference.xlsx`에는 2023년까지만 들어 있어서 2024년 이후 제재처분 비율이 공란이다. 2024년 이후 NTIS 조사·분석 결과는 이미 나와 있으므로(2026-10-23 사용자 확인) 바로 채울 수 있다. 채운 파일은 내려받기로 덮어써지지 않게 다른 이름으로 두고 화면에서 지정하거나, 소스의 `reference.xlsx`를 고쳐 다시 빌드한다.
